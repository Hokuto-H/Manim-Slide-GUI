# Manim Slide GUI

数式がきれいなまま、クリックで少しずつ進むアニメーション付きのスライドを作るアプリです。
文字・数式・図形・グラフを画面の上で並べ、どのクリックで何がどう動くかを選ぶだけで、スライドができます。
できたスライドは、専用の発表ウィンドウで発表したり、HTML・PDF・PowerPoint・動画のファイルにしたりできます。

- 数式は LaTeX で書き、本物の組版（TeX）で描かれます。
- 動きは「出す」「消す」「強調」「動かす」などを一覧から選びます。プログラムを書かなくても作れます。
- グラフ・統計のグラフ・3D・定理のブロック・幾何の作図など、数学の授業や発表で使う図を置けます。
- 編集も発表も、このパソコンの中だけで動きます（インターネットにつなぐのは、入れるときと、一部の出力のときだけです）。

このアプリは、[Manim Community](https://www.manim.community/) と [Manim Slides](https://github.com/jeertmans/manim-slides) を使って作った**非公式のツール**です。
Manim Community・Manim Slides の開発者とは関係がありません。

## 動く環境

- Windows 10（1809 以降）・Windows 11（64 ビット）
- Microsoft Edge（Windows に入っています。無い場合は Google Chrome）
- 入れるときに、インターネットへの接続（合わせて 1.5 GB ほどを取得します）
- ディスクの空き: 約 4 GB（TeX Live を入れる場合を含む）

## 入れ方

1. このレポジトリの **Releases**（右側の欄）から、いちばん新しい版の `ManimSlideGUI-Setup-<版>.exe` をダウンロードして実行します。
   管理者の権限は要りません（このユーザーだけに入れます）。
   「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します。
2. 入れる場所と、入れるもの（日本語フォント・デスクトップのショートカット）を選んで進みます。
3. アプリが使う部品を取得して入れます（10〜20 分ほど）。
4. 数式を組むための TeX Live が見つからないときは、入れるかを聞かれます。「はい」を押すと入れます（30 分〜1 時間ほど）。
   すでに TeX Live を入れている場合は、それを使います。
5. 終わると、スタートメニューに「Manim Slide GUI」と「Manim Slide GUI 説明書」ができます。

## 起動と終了

- **起動**: スタートメニュー（またはデスクトップ）の「Manim Slide GUI」を開きます。アプリ用の窓が開きます。
- **終了**: 窓を閉じると終了します。保存していない変更があるときや、描画の途中のときは、閉じる前に確かめる画面が出ます。
- 変更は自動で保存されます。

## 使い方を知るには

- **チュートリアル**: 初めて起動したときに案内が出ます。練習用のプロジェクトで、実際に操作しながら一通りの流れ（10 分ほど）を体験できます。
- **ヘルプ**: ツールバーの「？」で開きます。F1 キーを押すと、今使っている場所の説明が出ます。言葉で探すこともできます。
- **説明書**: スタートメニューの「Manim Slide GUI 説明書」（PDF）。ヘルプと同じ内容を、印刷できる形にしたものです。

## 更新とアンインストール

- **更新**: 新しい版のインストーラーを実行します。作ったプロジェクトと設定は、そのまま残ります。
- **アンインストール**: Windows の「設定 → アプリ」から行います。作ったプロジェクト・設定・TeX Live・フォントは消えません。

## 作ったプロジェクト

1 つの発表が 1 つのフォルダにまとまります。画像・動画・描画の結果・出力したファイルも、このフォルダの中に入ります。
フォルダごと移動・コピーしても、そのまま開けます。ほかのパソコンへ持っていくときは、ツールバーの「zip に固める」が便利です。

## 困ったとき

| 困りごと | 対処 |
| --- | --- |
| 描画・発表のボタンが押せない | ツールバーの「環境チェック」を開き、✕ の付いた項目のヒントに従います。TeX Live やフォントを入れた直後は、アプリを起動し直します |
| 描画でエラーが出る | 下のパネルに出る場所（スライド・要素・ステップ）を押して、そこを直します |
| 数式が赤字になる | 画面の上の仮の表示で扱えない命令です。「▷ このスライドを試す」で、正しく描かれるかを確かめます |
| 発表ウィンドウが開かない | スピーカー・ヘッドホンなど、音声の出力先があるかを確かめます（環境チェックの「音声の出力先」） |
| 部品が足りないと出る | インストーラーをもう一度実行します（入れ直します） |

ほかの困りごとは、ヘルプの「困ったとき」をご覧ください。
問い合わせるときは、`%LOCALAPPDATA%\ManimSlideGUI\logs\app.log`（アプリのログ）を添えてください。

### ダウンロードした exe を確かめる（任意）

Releases のページに、exe の SHA-256（ハッシュ値）を載せています。PowerShell で次を実行し、出た値が同じなら、途中で書き換えられていません。

```
Get-FileHash .\ManimSlideGUI-Setup-<版>.exe -Algorithm SHA256
```

インストーラーは、このレポジトリのソースから GitHub Actions で作っています（`.github/workflows/release.yml`）。
