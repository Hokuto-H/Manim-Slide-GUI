## このスライドを試す {#try}

ツールバーの **▷ このスライドを試す**（[[Ctrl+Enter]]）で、編集中のスライドだけを低い画質で描画し、キャンバスの上の小窓で再生します。

![試し描画の小窓](player.png)

| 操作 | キー |
| --- | --- |
| 次へ ▶ / ◀ 前へ | [[→]]・[[Space]] / [[←]] |
| その区切りをもう一度 | [[R]] |
| 一時停止・再生 | [[K]] |
| 1 コマずつ | [[,]] / [[.]] |
| 閉じる | [[Esc]] |

「通しで再生」で初めから最後まで続けて再生し、「描画し直す」で直したあとにもう一度描きます。
小窓で見ている区切りのステップが、下の動きの欄で開きます。

## 描画・発表 {#render}

ツールバーの **▶ 描画・発表** で、全体を描画し、終わると発表ウィンドウを開きます。
進み具合と残り時間の目安が、下の欄に出ます。変えていないスライドは、2 回目から速くなります。

### 品質 {#quality}

| 品質 | 向いているとき |
| --- | --- |
| 低（480p） | 動きの確認 |
| 中（720p） | 通しの確認 |
| 高（1080p） | 本番 |
| 高（1080p・30fps） | 3D など描画が重いとき（時間はほぼ半分） |

## 描画するスライドを選ぶ {#select}

ツールバーの「描画: …」で選びます。

- **印の通り**（既定）: 「描画しない」の印を付けたスライドを除きます。
- **このスライドだけ**
- **選んで描画…**: チェックしたスライドだけ。直したスライドだけを描き直したいときに。

## 時間がかかるとき {#slow}

- 画像を動かす・3D を回す動きは、1 コマごとに時間がかかります。確かめるときは低い品質にします。
- 「ずっと回す」の 1 周を描くときは、描画を始めるときに長さを知らせます。
