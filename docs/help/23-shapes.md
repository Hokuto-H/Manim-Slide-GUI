## 図形メニュー {#menu}

**＋図形 ▾** を押すと、7 つのタブに分かれた一覧が出ます。前回開いたタブを覚えます。

![図形メニュー（基本図形のタブ）](shapemenu.png)

| タブ | 主なもの |
| --- | --- |
| 基本図形 | 長方形・円・楕円・多角形・星・円弧・扇形・点・円環 |
| 線・注釈 | 直線・矢印・破線・中かっこ・角の印・囲み枠・下線・×印・ベクトル・ズーム・軌跡 |
| グラフ・座標 | 数直線・座標軸・座標平面・極座標・複素平面・関数のグラフ・頂点と辺のグラフ |
| 表・数値・文字 | 表・行列・コード・棒グラフ・数値・LaTeX の文章・題名・箇条書き・標本空間 |
| 統計のグラフ | 散布図・折れ線・縦棒・横棒・帯・ヒストグラム・箱ひげ図・円グラフ |
| 定理・作図・計算 | 定理・証明のブロック、幾何の作図、数値計算 |
| 3D | 球・立方体・円錐・円柱・多面体・3D 座標軸（3D のプロジェクトだけ） |

項目の下の小さな文字は、対応する Manim の名前です。

> **ヒント** 「角」「中かっこ」「囲み枠」などは、**付ける相手を先に選んでから** メニューを押します。相手を動かすと一緒についてきます。

## 線と矢印 {#lines}

- 両端の丸をドラッグして動かします。ほかの要素の端・中心に吸い付きます（[[Alt]] で吸い付かない、[[Shift]] で 15° 刻み）。
- 線の真ん中のオレンジの丸をドラッグすると曲げられます。
- パネルで、矢じりの形・太さ・破線・色・ラベルを変えます。

## 手書き・ベジェ曲線 {#path}

- **手書き**: ドラッグで描きます。何筆でも 1 つの要素になり、[[Enter]] で完成します。
- **ベジェ曲線**: クリックで角の点、ドラッグで曲がる点を打ちます。最初の点を押すと閉じ、[[Enter]] で完成します。
- あとから形を直すときは、曲線をダブルクリックして点を動かします。

## 吹き出し {#balloon}

中身（テキスト・数式など）を囲む枠で、中身に合わせて伸び縮みします。尾の先（オレンジの丸）はドラッグで動かします。
既にある要素を右クリックして「吹き出しで囲む」でも作れます。

## 表・行列 {#table}

セルを選んで、パネルで内容を書き、行・列を足したり消したりします。Excel などでコピーした範囲を、セルに貼り付けられます。
`$x^2$` のように `$` で囲んだセルは数式になります。

## 図形の合成 {#boolean}

2 つ以上の図形を選んで「合成: 和」「共通部分」「切り抜き」「重ならない部分」で、新しい形を作ります。

## 部品 {#parts}

よく使う要素の組（記号・図のひな形など）を 1 回作って保存し、どのプロジェクトでも 1 つの要素として置けます。

1. 要素を複数選び、パネルの **部品として保存…** を押します。
2. 次からは、キャンバスの上の **＋部品 ▾** から選んで置きます。
3. 直したいときは、部品のパネルの **部品を直す…** でばらし、直してから「部品「…」を上書き」を押します。置いた所がすべて変わります。
