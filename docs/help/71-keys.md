## 編集画面 {#editor}

| キー | 動き |
| --- | --- |
| [[Ctrl+S]] | 保存 |
| [[Ctrl+Z]] / [[Ctrl+Y]] | 元に戻す / やり直す |
| [[Ctrl+C]] / [[Ctrl+X]] / [[Ctrl+V]] | コピー / 切り取り / 貼り付け |
| [[Ctrl+D]] | 複製 |
| [[Delete]] | 削除 |
| [[Ctrl+A]] | すべて選ぶ |
| [[Esc]] | 選択の解除（入力欄では 1 回目で欄から外れる） |
| [[Ctrl+G]] / [[Ctrl+Shift+G]] | グループ化 / 解除 |
| [[Ctrl+]]] / [[Ctrl+[]] | 前面へ / 背面へ |
| [[Ctrl+Shift+]]] / [[Ctrl+Shift+[]] | 最前面へ / 最背面へ |
| 矢印 / [[Shift]]＋矢印 | 1px / 10px 動かす |
| [[Ctrl+B]] / [[Ctrl+I]] / [[Ctrl+U]] | 太字 / 斜体 / 下線 |
| [[Ctrl+Shift+F]] / [[Ctrl+H]] | 検索 / 置換 |
| [[Ctrl+Enter]] | このスライドを試す |
| [[F1]] | ヘルプ |
| [[Alt]]（押しながら） | 吸い付かない |
| [[Shift]]（押しながら回す） | 15° 刻み |

## 試し描画の小窓 {#preview}

| キー | 動き |

| [[R]] | もう一度 |
| [[K]] | 一時停止・再生 |

| [[Esc]] | 閉じる |

## 発表ウィンドウ {#present}

| キー | 動き |
| --- | --- |
| クリック・[[→]]・[[PageDown]] | 次へ |
| 右クリック・[[←]]・[[PageUp]] | 前へ |
| [[F]] | フルスクリーンの切り替え |
| [[Q]] | 終わる |
| 番号＋[[Enter]] | そのページへ |
| [[L]] / [[P]] / [[Z]] | レーザー / ペン / 拡大鏡 |
| [[B]] / [[W]] | 黒画面 / 白画面 |
| [[Ctrl+R]] / [[Ctrl+Shift+R]] | 録画の開始・一時停止 / 終了 |
| [[?]] | 道具の一覧 |
