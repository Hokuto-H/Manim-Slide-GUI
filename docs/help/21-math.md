## 数式を置く {#add}

**＋数式** を押し、パネルの欄に LaTeX で書きます。例:

| 書く | 出る |
| --- | --- |
| `x^2` | x の 2 乗 |
| `\frac{1}{2}` | 2 分の 1 |
| `\sqrt{x}` | ルート x |
| `\int_0^1 f(x)\,dx` | 0 から 1 までの積分 |
| `\sum_{k=1}^{n} k` | k の和 |
| `\text{面積}` | 数式の中の日本語 |

数式の中に日本語を書くときは `\text{…}` で囲みます。

> **注意** キャンバスの数式は仮の表示（MathJax）です。仮表示で赤字になる命令も、描画では正しく出ることがあります。正確な見た目は「▷ このスライドを試す」で確かめます。

## 記号の表（Σ 記号） {#palette}

数式の欄を選ぶと、右上に **Σ 記号** が出ます。分数・根号・ギリシャ文字・矢印などを押すと、カーソルの位置に入ります。
`▮` は入れる場所の目印です。

## 複数行と揃え {#lines}

`\\` で改行します。行の揃え方はパネルの「複数行の揃え」で選びます。`&` を書くと、その位置で揃います。

## 一部に色を付ける {#color}

パネルの「一部の色」で、色を付ける文字（`x`・`\pi` など）と色を決めると、数式の中の同じ文字すべてに色が付きます。

## 式を少しずつ書く・変形する {#transform}

- 動きの行の「一部分…」で、数式の一部だけを出す・強調できます。
- 「変形」の動きで、ある数式を別の数式に変えます。「対応を決めて変える」で、どの部分がどこへ移るか（移項など）を自分で決められます（[アニメーション](help:animation#transform)）。

## 共通プリアンブル {#preamble}

ツールバーの **共通プリアンブル** に、`\usepackage{…}` や `\newcommand` を書くと、すべての数式で使えます。
保存すると試しに組んで、誤りがあれば何行目かを示します。

## 式の番号と参照 {#ref}

数式のパネルの「番号・ラベル」で「式の番号 (1.1) を付ける」と、式の右に番号が付きます。
ほかの文字の中に `{ref:ラベル}` と書くと「(1.1)」になります（[定理・番号・参照](help:theorem#ref)）。
