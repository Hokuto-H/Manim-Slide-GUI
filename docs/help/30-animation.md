## 動きを付ける流れ {#flow}

1. キャンバスで要素を選びます。
2. 右のパネルの **＋出す**・**＋消す**・**＋強調**・**＋動かす** のどれかを押します。
3. キャンバスの下の動きの欄に、新しいステップ（クリック 1 回分）ができ、その下に動きの行の編集欄が開きます。
4. 行で、動きの種類・時間・緩急（だんだん速く など）・動きごとの設定（向き・色など）を変えます。

「出す」動きを付けた要素は、初めは見えない（薄く表示）になります。

## 動きの種類 {#kinds}

| 分類 | 例 |
| --- | --- |
| 出す | フェードで出す・書く・線を描く・中心から大きく・滑り込む・1 文字ずつ打つ・部品を少しずつずらして出す |
| 消す | フェードで消す・縮んで消える・書いたのを消す |
| 強調 | 目立たせる・囲む・揺らす・波打たせる・点滅・光を放つ |
| 動かす | 移動・拡大・縮小・回転・左右反転・上下反転・色を変える・線に沿って動く・覚えた状態に戻す |
| 変形 | 形を変える・同じ形を合わせて変える・対応を決めて変える・位置を入れ替える |
| ずっと動かす | ずっと回す・進め続ける・ほかの要素について行く |
| そのほか | 値を変える・カメラ・動画の操作・待つ・コード |

左右反転・上下反転は、鏡に映したように裏返します（途中で幅・高さが細くなります）。境を「決めた線」にすると、x = 0（y 軸）や y = 0（x 軸）について対称な位置へ裏返せます。

移動先・回転の中心・カメラの枠は、キャンバスに薄い影で示され、ドラッグで決められます。

## 同じクリックで、別の要素も動かす {#together}

PowerPoint の「直前の動作と同時」「直前の動作の後」に当たるものです。

1. 下でステップを選んだまま、別の要素を選びます。
2. 右のパネルの「ステップ k に足す」の **＋出す** などを押します。
3. 足した行の「始まり」で、**前と同時**・**前の後に**・**前の始まりから○秒後** を選びます。

複数の要素を選んで「＋出す」を押すと、1 つのクリックでまとめて出せます（「少しずつずらす」で時間差も付けられます）。

## 一部分だけ動かす {#parts}

テキスト・数式・表・箇条書き・コードなどは、行の **一部分…** を押すと、キャンバスに番号の付いた枠が出ます。
押して選び（[[Shift]] で範囲）、**決める** を押すと、その部分だけが動きます。数式を少しずつ書くときに使います。

## 変形 {#transform}

「変形」の動きで、「変えた先」に別の要素を選ぶと、形が変わります。
**対応を決めて変える** では、① 元の部品 → ② 変えた先の部品 の順にキャンバスで選び、どこがどこへ移るかを決めます（移項・約分を見せるのに向きます）。

## 並べ替え・写す {#order}

- ステップは一覧をドラッグして並べ替えます。行は ↑↓ で並べ替えます。
- 行の ⧉ やステップの「⧉ ステップを写す」で写し、別の要素・別のスライドに貼り付けられます。

## タイムライン {#timeline}

動きの欄の「一覧／タイムライン」で切り替えます。動きを時間の帯で並べ、ドラッグで始まりを、右端のドラッグで長さを変えます。

## 動きのプリセット {#presets}

**動きのプリセット ▾** で、よく使う動き（出して強調、出して次のクリックで消す など）を選んだ要素に当てます。
今の動きに名前を付けて、自分のプリセットとして保存することもできます。

## 発表での進み方 {#playback}

ステップの見出しの下で決めます。

- **くり返す**: 次のクリックまで、そのステップの動きをくり返します。
- **終わったら自動で次へ**: クリックを待たずに次へ進みます。
- **発表者ノート**: そのステップを見せている間に、発表者用の画面に出すメモです。

## 確かめる {#try}

編集欄の **▷ このステップを試す** で、そのステップの区切りから再生します（[試す・描画する](help:preview-render#try)）。
