## 発表を始める {#start}

- **▶ 描画・発表**: 描画してから発表ウィンドウを開きます。
- **発表のみ**: 前回の描画のまま開きます。
- 開き方（最大化・フルスクリーン・通常）と、発表者用の画面を出すか（画面が 2 つなら・常に・出さない）は、ツールバーの選択欄で決めます。

発表の前に自動で点検し、気になる所があれば知らせます（[点検](help:lint)）。

## 発表ウィンドウの操作 {#keys}

| 操作 | キー・マウス |
| --- | --- |
| 次へ | クリック・[[→]]・[[PageDown]] |
| 前へ | 右クリック・[[←]]・[[PageUp]] |
| フルスクリーンの切り替え | [[F]] |
| 終わる | [[Q]] |
| そのページへ飛ぶ | 番号を打って [[Enter]]（「3-2」で 3 ページの 2 回目のクリック、「A2」で付録） |
| 道具の一覧 | [[?]] |

プレゼン用のリモコン（PageDown・PageUp を送るもの）もそのまま使えます。

## 発表の道具 {#tools}

| キー | 道具 |
| --- | --- |
| [[L]] | レーザーポインター |
| [[P]] | ペン（[[C]] で色、[[E]] でそのページの線を消す、[[M]] で蛍光ペン） |
| [[B]] / [[W]] | 黒画面 / 白画面 |
| [[Z]] | 拡大鏡（[[+]] [[-]] で倍率） |
| [[Esc]] | 道具をまとめてやめる |

## 発表者用の画面 {#presenter}

画面が 2 つあるとき（または「常に表示」のとき）に出ます。今と次のスライド、全ページの一覧（押すとそこへ飛ぶ）、発表者ノート、タイマー（目安を過ぎると赤）が出ます。

## リハーサル {#rehearsal}

発表者用の画面の **● リハーサルを始める** で、ページごとにかかった時間を記録します。
ツールバーの **リハーサル** で、2 回の記録を比べたり、記録の時間を「発表の目安」や「動画での待ち」に入れたりできます。
ツールバーの **見通し** では、スライドごとの動きの時間・目安・リハーサルの時間を並べて見られます。

## 録画 {#record}

発表ウィンドウで [[Ctrl+R]] を押すと録画を始め、もう一度で一時停止、[[Ctrl+Shift+R]] で終えます。
スライドの動き・ペンの書き込み・マイクの声・カメラの小窓が 1 本の動画になります（プロジェクトの `recordings` フォルダ）。
マイク・カメラの設定と録画の一覧は、ツールバーの **● 録画** です。

> **注意** Windows では、初めてマイク・カメラを使うときに「設定 → プライバシーとセキュリティ → マイク（カメラ）」で、デスクトップアプリの利用を許可してください。
