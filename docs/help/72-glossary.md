## 用語 {#terms}

| 用語 | 意味 |
| --- | --- |
| スライド | 発表の 1 ページ |
| ステップ | クリック 1 回分の動き |
| 区切り | クリックで止まる所。「3-2」は 3 ページの 2 回目のクリックの後 |
| 初めの表示 | スライドを開いた直後、まだクリックしていないときの画面 |
| 動きの行 | ステップの中の 1 つの動き |
| 要素 | キャンバスに置いた 1 つの物（テキスト・数式・図形・画像など） |
| 変数名 | 要素の名前。コードで要素を指すときに使う（`eq1` など） |
| 描画 | スライドを本物の動画にする処理 |
| 仮表示 | キャンバスの表示。描画とはわずかに違うことがある |
| 発表ウィンドウ | 描画した動画をクリックで進めながら映す窓 |
| 発表者用の画面 | 発表者だけが見る、次のスライド・ノート・タイマーの窓 |
| 共通プリアンブル | すべての数式で使う LaTeX の設定（`\usepackage` など） |
| スライドマスター | 全スライドに共通で出す要素と設定 |
| スライドの値 | スライドで使う数。動かすとグラフなどが変わる |
| 部品 | 保存した要素の組。どのプロジェクトでも置ける |
| LaTeX | 数式を書くための書き方（`\frac{1}{2}` など） |
| Manim | アニメーションを描くプログラム。このアプリは裏で使う |
| Manim Slides | Manim の動画をクリックで進めて発表する仕組み |
| TeX Live | LaTeX を動かすためのソフト一式 |
