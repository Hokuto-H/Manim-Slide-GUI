## 環境チェック {#env}

起動するたびに、LaTeX（XeLaTeX と日本語のパッケージ）・数式の変換・Manim・発表ウィンドウの部品・音声の出力先・フォントを調べます。
ツールバーの右の **環境チェック** で結果を見られ、✕ の項目にはヒントが出ます。

## フォント {#fonts}

既定のフォントは Noto Sans JP（ゴシック）と Noto Serif JP（明朝）です。インストーラーは、入っていなければ自動で入れます。
ほかのフォントは、このパソコンに入れるか、プロジェクトのフォントとして入れます（[文字](help:text#fonts)）。
フォントを入れたあとは、アプリを起動し直してください。

## TeX Live {#tex}

数式を組むのに TeX Live を使います。インストーラーは、見つからないときに入れるかを聞きます（日本語と数式に必要な分だけ。数 GB のダウンロードで、30 分〜1 時間ほどかかります）。
既に TeX Live を入れている場合は、それを使います。パッケージが足りないときは、エラーに入れ方（`tlmgr install …`）が出ます。

## ユーザーの設定 {#userdata}

テンプレート・部品・動きのプリセット・出力の設定などは、このパソコンのユーザーの設定フォルダ（`%APPDATA%\ManimSlideGUI`）に保存し、どのプロジェクトでも使えます。

## 更新とアンインストール {#update}

- **更新**: 新しい版のインストーラーを実行します。プロジェクトと設定はそのまま残ります。
- **アンインストール**: Windows の「設定 → アプリ」から行います。プロジェクト・ユーザーの設定・TeX Live は消しません。
