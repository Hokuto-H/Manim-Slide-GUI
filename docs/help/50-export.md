## 出力の前に {#before}

ファイルは、**直前に描画した結果** から作ります。描画したあとに内容を変えたときは、画面に注意が出るので、先に **▶ 描画・発表** で描き直してください。
出力したファイルは、プロジェクトの `export` フォルダに入ります（「フォルダを開く」で開けます）。

## 形式 {#formats}

| 形式 | 中身 | メモ |
| --- | --- | --- |
| HTML | ブラウザで発表（動き・ノート付き） | 初めての出力のときだけ、確認してから部品をダウンロードします |
| PDF | クリックの区切りごと、またはスライドごとの画面 | リンク・参照も押せます |
| PowerPoint | 区切りごとの動画を 1 枚ずつ | クリックで再生。ノートも入ります |
| 動画（mp4） | クリックせずに最後まで流した 1 本の動画 | 区切りで待つ秒数を決めます。字幕（.srt）も作れます |
| 配布資料（PDF） | 画面を用紙に並べたもの | 1〜9 枚、ノートやメモ欄付き |
| 画像（PNG） | ページごと・ステップごとの画像 | |
| 動く画像（GIF） | スライドごとの動き | |

## まとめて出力 {#batch}

1. **ファイルに出力…** を開きます。
2. 形式や保存した設定にチェックを入れます（「すべて選ぶ」で全部）。
3. **まとめて出力…** で、上から順に出力します。

今の形式と設定は「この設定を保存…」で名前を付けて残せます。
