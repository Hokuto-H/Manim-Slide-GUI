## このアプリでできること {#about}

Manim Slide GUI は、**数式がきれいなまま、クリックで少しずつ進むスライド**を作るアプリです。
文字・数式・図形・グラフは画面の上で並べ、どのクリックで何がどう動くかを選ぶだけで、アニメーション付きのスライドになります。
できたスライドは、専用の発表ウィンドウで発表したり、HTML・PDF・PowerPoint・動画のファイルにしたりできます。

- 数式は LaTeX（`\frac{1}{2}` のような書き方）で書き、本物の組版で描かれます。
- 動きは「出す」「消す」「強調」「動かす」などを一覧から選びます。プログラムを書かなくても作れます。
- 書きたい人は、動きを Manim（Python）のコードで書くこともできます。

> **ヒント** 初めての方は、ヘルプの「[初めてのスライドを作る](help:tutorial)」か、ツールバーの「？」→「チュートリアルを始める」で、実際に手を動かしながら一通りの流れを体験できます。

## 起動と終了 {#launch}

- **起動**: スタートメニュー（またはデスクトップ）の **Manim Slide GUI** を開きます。アプリ用の窓が開きます。
- **終了**: 窓を閉じると終了します。保存していない変更や、描画の途中のときは、閉じる前に確かめる画面が出ます。
- 起動するたびに、必要なもの（LaTeX・フォントなど）がそろっているかを調べます。足りないものがあれば「環境チェック」に ✕ が付きます（[困ったとき](help:trouble#env)）。

## 画面の見方 {#screen}

![編集画面。左にスライドの列、中央にキャンバス、下に動きの欄、右にプロパティ](screen.png)

| 場所 | 名前 | すること |
| --- | --- | --- |
| いちばん上 | ツールバー | 新規・開く・保存、点検、描画・発表、ファイルに出力 など |
| 左 | スライドの列 | スライドの追加・並べ替え・選択。下にレイヤー（重なり順）の一覧 |
| 中央 | キャンバス | スライドの中身を置いて動かす所（16:9） |
| キャンバスの上 | 追加のボタン | ＋テキスト・＋数式・＋図形・＋画像・＋動画・音声・＋部品・表示 |
| キャンバスの下 | 動きの欄 | このスライドのアニメーション（クリック順）。ステップの一覧と編集欄 |
| 右 | プロパティ | 選んでいる物の設定（何も選んでいなければスライドの設定） |
| いちばん下 | 下のパネル | エラーと描画のログ（必要なときに開きます） |

## ヘルプの使い方 {#help}

- ツールバーの **？** でこのヘルプを開きます。[[F1]] でも開き、今使っている場所（選んでいる要素の種類や開いている画面）に合った説明が出ます。
- パネルやダイアログの見出しの横の **？** を押すと、その機能の説明へ直接移ります。
- 上の検索の欄に言葉を入れると、すべてのページから探せます。
- 同じ内容は、印刷できる説明書（PDF）にもなっています（ヘルプの上の「説明書: PDF」）。
- アプリの版と、使っている部品のライセンスは「[このアプリについて・ライセンス](help:about)」にあります。
