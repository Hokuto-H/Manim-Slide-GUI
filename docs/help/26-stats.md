## 種類 {#kinds}

**＋図形 ▾ → 統計のグラフ** から置きます。パネルの「グラフの種類」で、同じデータのまま種類を変えられます。

| 種類 | 主な設定 |
| --- | --- |
| 散布図 | 回帰直線（式と R²）、誤差棒 |
| 折れ線グラフ | 系列を重ねる、誤差棒 |
| 集合縦棒・積み上げ縦棒 | 横向き、100% にそろえる（帯グラフ）、棒の中の値 |
| ヒストグラム | 区間（自動・数・幅）、度数か密度、区間の端（以上・未満／超・以下） |
| 箱ひげ図 | 四分位数の求め方（教科書の求め方が既定）、ひげの長さ、外れ値 |
| 円グラフ | ドーナツ、始まりの向き |

## データを入れる {#data}

- パネルの表で直接書きます。1 行目は見出し（系列の名前）です。[[Enter]] で下のセルへ進みます。
- Excel などでコピーした範囲を、セルに貼り付けると、そこから右下へ書き込みます。
- 「CSV・表計算からの貼り付け」に CSV を貼り、**表を置き換える** か **下に足す** を押します。カンマ・タブ・セミコロン区切りを自動で見分けます。
- 行番号をドラッグして行を並べ替えられます。
- 表は 500 行・16 列までです。

## 列の使い方・軸・見た目 {#options}

- **列の使い方**: 横軸・分類の列、系列（色・誤差・回帰直線）、値の列を選びます。
- **軸**: 範囲は自動（きりのよい数）か手動。軸の名前には日本語も書けます。
- **見た目**: 大きさ、点や線の太さ、棒の幅、文字の色と大きさ、凡例の位置（グラフの中の空いている角・右・上・下・なし）、小数の桁。

## 出し方 {#animate}

グラフを選んで **＋出す** を押すと、座標軸を先に出してから、点・棒などを順に出します（誤差棒・回帰直線は最後）。
