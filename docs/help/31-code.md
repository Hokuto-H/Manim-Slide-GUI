## コードの行・コードのステップ {#code}

Manim（Python）を知っている方は、動きをコードで書けます。

- 動きの行の **＋コード** で、ほかの動きの間にコードを入れます（前の動きが終わってから実行します）。
- 要素を選んで **＋ステップを追加** で、クリック 1 回分をコードだけで書きます。
- GUI のステップを **コードにする** で、作られたコードを元にして書き換えられます（GUI には戻せません）。

例:

```
self.play(Write(eq1), run_time=2)
self.play(eq1.animate.shift(UP))
```

## 変数名 {#names}

各要素には変数名（`text1`・`eq1`・`circle1` など）が付いていて、パネルの上で変えられます。
テキストは行ごと・文字ごとに分かれ、`title[0]` は 1 行目、`title[0][2]` は 1 行目の 3 文字目です。

## 書き出したコードを見る {#view}

動きの欄の「書き出すコード」で、そのステップのコードを見られます。
ツールバーの **書き出し** で、プロジェクトのフォルダに Manim Slides の `.py` を書き出します。ターミナルから次のようにも使えます。

```
manim-slides render Deck.py Deck
manim-slides present Deck
```

> **注意** コードの欄に書いたものは、描画のときにそのまま実行されます。人からもらったプロジェクトは、中身を確かめてから描画してください。

## エラーが出たとき {#errors}

描画でエラーが出ると、下のパネルに「スライド 2 / 要素 eq / ステップ 3 / 5 行目」のように場所を示し、押すとその場所へ移ります。
