## 環境チェックに ✕ が付く {#env}

✕ の項目のヒントに従います。TeX Live やフォントを入れた直後は、アプリを起動し直します。

## よくある困りごと {#faq}

| 困りごと | 対処 |
| --- | --- |
| 描画でエラーが出る | 下のパネルの場所を押して、そのステップ・要素を直します。LaTeX のパッケージが足りないときは、入れ方が出ます |
| 数式が赤字になる | 仮の表示で扱えない命令です。「▷ このスライドを試す」で正しく出るか確かめます |
| 発表ウィンドウが開かない | 環境チェックの「音声の出力先」を確かめます（スピーカー・ヘッドホンをつなぐか、出力先を有効にします）。下のパネルのログも見ます |
| フォントが反映されない | 環境チェックでそのフォントが ✓ か確かめ、アプリを起動し直します |
| 「このタブでは保存できません」と出る | 別のタブや窓で、別のプロジェクトを開いています。このタブで続けるときは「このタブで作業を続ける」を押します |
| 描画に時間がかかる | 品質を「低」にする、「描画: 選んで描画…」で直したスライドだけ描く |
| 新しい機能のボタンが反応しない | アプリを閉じて起動し直します |
| 前の状態に戻したい | [[Ctrl+Z]]、または「バックアップ」から戻します |

## インストールのとき {#install}

- **「Windows によって PC が保護されました」と出る**: インストーラーに署名が無いためです。「詳細情報」を押してから「実行」を押します。
- **ダウンロードに失敗する**: インターネットにつながっているか確かめて、もう一度インストーラーを実行します（続きから入れます）。

## それでも直らないとき {#report}

下のパネルの「描画ログ」の内容と、環境チェックの結果を添えて、配布した方に知らせてください。
