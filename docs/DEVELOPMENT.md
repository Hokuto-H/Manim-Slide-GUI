# Manim Slide GUI 開発者向けの資料

利用者向けの説明は、リポジトリの README.md とアプリ内のヘルプ（`docs/help`）にあります。ここは、機能の詳しい一覧・開発用の導入・ファイルの役割をまとめた資料です。

LaTeX の数式を保ったまま、クリックで進むアニメーション付きスライドを作るための、Manim Slides 用の GUI です。
テキスト・数式の配置は GUI で行い、アニメーションだけを Manim のコードで書きます。書き出した `.py` は
`manim-slides render` / `manim-slides present` でそのまま使えます。アプリはすべてローカル（127.0.0.1）で動き、
動作中はインターネットに接続しません。

## 導入（インストーラー）

`ManimSlideGUI-Setup-<版>.exe` を実行します（このユーザーだけに入れるので、管理者の権限は要りません）。

1. 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します（インストーラーに署名が無いため）。
2. 入れる場所（既定は `%LOCALAPPDATA%\Programs\ManimSlideGUI`。ユーザー名に日本語・空白があるときは `C:\ManimSlideGUI`）と、
   入れるもの（日本語フォント・デスクトップのショートカット）を選びます。
3. 入れるときに、インターネットから次のものを取得します。
   - アプリが使う部品（Python・Manim・Qt など。conda-forge から micromamba で。約 450 MB・10〜20 分）
   - 日本語フォント（Noto Sans JP・Noto Serif JP。入っていなければ、このユーザーに入れます）
   - TeX Live（xelatex が見つからないときは、入れるかを聞きます。日本語と数式に要る分で約 1 GB・30 分〜1 時間）
4. 終わると、スタートメニューに「Manim Slide GUI」と「Manim Slide GUI 説明書」ができます。

- **起動と終了**: スタートメニュー（またはデスクトップ）の「Manim Slide GUI」で、アプリ用の窓（Edge。無ければ Chrome）が開きます。
  窓を閉じると終了します（未保存の変更・描画や出力の最中は、閉じる前に確かめます）。2 回目に起動すると、動いているアプリの窓をもう 1 つ開きます。
  コンソールの窓は出ません。ログは `%LOCALAPPDATA%\ManimSlideGUI\logs\app.log` です。
- **更新**: 新しい版のインストーラーを実行します（同じ場所を更新します。プロジェクトと設定はそのまま）。
- **アンインストール**: Windows の「設定 → アプリ」から。プロジェクト・ユーザーの設定（`%APPDATA%\ManimSlideGUI`）・TeX Live・フォントは消しません。
- **使い方の案内**: ツールバーの「？」（F1 で、今の場所の説明）、初めて起動したときのチュートリアル、説明書（HTML・PDF）。

## 導入（開発用・conda）

1. **TeX Live** を導入します（XeLaTeX と日本語パッケージを使います）。
   - インストーラーの既定（scheme-full）なら必要なものはそろっています。最小構成の場合は、
     `tlmgr install collection-langjapanese` で `zxjatype`・`zxjafont`・IPAex フォントを入れます。
   - `dvisvgm`（数式の変換に使う）も TeX Live に含まれます。
2. **フォント**（任意）: 既定は Noto Sans JP（ゴシック）です。未導入のフォントを選ぶと警告が出ます。
   フォントの選択肢には、プリセット・プロジェクトのフォントのほかに「この PC のフォント」（游ゴシック・メイリオなど）も出ます。
   プリセットは同じ書体の別名（Noto Sans JP と Noto Sans CJK JP など）を、PC にある方で描きます（保存した名前は書き換えません）。
3. **conda 環境**を作ります。

   ```
   conda env create -f environment.yml
   conda activate manim-slide-gui
   manim --version          # Manim Community v0.20.1
   manim-slides --version   # manim-slides, version 5.7.0
   pip check                # No broken requirements found.
   ```

   既に環境を作っている場合は、`conda env update -n manim-slide-gui -f environment.yml` で版を合わせます
   （manim を 0.20.1 にする理由は VERSIONS.md）。

## 起動（開発用）

```
conda activate manim-slide-gui
python run.py
```

ブラウザが開きます（http://127.0.0.1:8765/）。`start.bat` をダブルクリックしても起動できます。
配布版と同じ起動（アプリ用の窓・窓を閉じたら終了）を試すときは `python launcher.pyw` です。

| オプション | 内容 |
| --- | --- |
| `--port 9000` | ポートを変える（使用中なら次の空きポートを自動で使う） |
| `--no-browser` | ブラウザを自動で開かない |
| `--open フォルダ` | プロジェクトを開いた状態で起動する |

終了は、起動したターミナルで Ctrl+C です。

### 配布物を作る

GitHub に公開している場合は、`app/__init__.py` の `__version__` を上げてコミットし、同じ版のタグ（例: `v1.0.1`）を push すると、
GitHub Actions（`.github/workflows/release.yml`）がインストーラーを作り、Releases に exe と SHA-256 を置きます。手元で作るときは次のとおりです。

```
python scripts/capture_help_images.py --work 作業用のフォルダ   # ヘルプの画面の画像（アプリを起動しておく）
python scripts/build_manual.py                                  # 説明書 docs/manual/manual.html・manual.pdf
python installer/build_installer.py                             # dist/ManimSlideGUI-Setup-<版>.exe（makensis が要る）
```

## 使い方

ここは機能の一覧です。操作の説明は、アプリ内のヘルプ（`docs/help/*.md`。説明書も同じ原稿）にあります。

0. **使い方の案内**（段階 5）:
   - **ヘルプ**: ツールバーの「？」で右に開きます。目次・検索（ひらがなでカタカナも、全角・半角も見つかる）・ページの中の見出しへのリンク・戻る。
     **F1** で今の場所（開いているダイアログ・選んでいる要素の種類・動きの欄）に合ったページを開きます。ダイアログ・パネルの見出しの「？」からも開きます。
     ダイアログを開いているときは、ヘルプをダイアログの中に出すので、そのまま読めます（Esc でヘルプだけ閉じる）。
   - **チュートリアル**: 初めて起動したときの画面の案内、初めの画面の「チュートリアル」、ヘルプの「チュートリアルを始める」から。
     ドキュメントの `ManimSlideGUI` フォルダに練習用のプロジェクトを作り、次に押す所を橙の枠で示し、操作が済んだら（プロジェクトの中身を見て）自動で次へ進みます
     （文字を置く → 題名を書く → 動かす → 数式を置く → 書く → ＋出す → 試す → 次へ ▶ → まとめ。全 10 段階）。やめても、次は続きから始められます。
   - **説明書**: ヘルプと同じ原稿から、1 つの HTML（画像入り）と A4 の PDF（目次・ページ番号付き）を作ります。ヘルプの上の「説明書: HTML／PDF」、スタートメニューの「説明書」から開きます。

1. **新規プロジェクト**: 名前・保存先・背景色・既定のフォント／文字サイズ／文字色・共通プリアンブルの初期内容を
   1 つのダイアログで決めます。保存先にプロジェクト名のフォルダが作られます。
2. **要素を置く**: 「＋テキスト」「＋数式」で追加し、ドラッグで動かします。内容・文字サイズ・色・フォント・座標は
   右のパネルで変えます。数式の中の日本語は `\text{…}` で書きます。
   - **テキストの書式**: 編集欄で文字を選び、太字・斜体・下線・取り消し線・色・マーカー・不透明度を付けます
     （選んでいないときは全体に付きます）。Ctrl+B / Ctrl+I / Ctrl+U も使えます。編集欄の文字は、要素の文字色に関係なくいつも黒で表示し、
     一部に付けた色は、その文字の下の太い線の色で示します。
   - **段落**: 配置（左・中央・右・両端）、文字間隔（em）、行間隔（倍）、縦書き、全体の不透明度。
   - **文字の効果**: 縁取り・中抜き、背景ボックス、円弧（文字列を曲げる）。
   - テキストのキャンバス表示は、書き出しと同じ関数で Manim が作った形そのものなので、実描画と一致します。
   - コードでは、テキストは行（縦書きは列）ごとに分かれています。`title[0]` で1行目、`title[0][2]` で1行目の3文字目です。
3. **アニメーション**: キャンバスの下の「このスライドのアニメーション」に、クリック 1 回分ずつの「ステップ」が並びます。
   - **GUI で作る**: 要素を選んで右のパネルの「＋出す」「＋消す」「＋強調」を押すか、下の「＋ステップ」を押します。
     ステップを押すと、その下に「動きの行」の編集欄が出ます。行ごとに、始まり方（クリックですぐ・前と同時・前の後に・
     前の始まりから○秒後）、対象の要素、動き（出す 12 種・消す 6 種・強調 10 種のほか、動かす・変形・値・カメラなど。全部で 68 種）、時間、緩急、動きごとの設定（向き・色など）を選びます。
     「＋動き」「＋待つ」「＋コード」で行を足し、↑↓で並べ替えます。「書き出すコード」を開くと、作られる Manim のコードを見られます。
     同じクリックの中で時刻をずらした動きは、1 つの `self.play(…)` にまとめ、`gui_at(動き, 始まる秒, 全体の秒)` で始まりをずらします。
     「＋コード」の行には Manim のコードを直接書けます（前の動きが終わってから実行します）。
     同じ要素に、出す・消す動きと強調（目立たせる・揺らす・波打たせる・点滅）を同時に（または途中から）掛けられます
     （`gui_stack(…)` にまとめて書き出します）。同じ要素を同時に出す・消す動き 2 つは使えません。
   - **同じクリックで、別の要素も動かす**（PowerPoint の「直前の動作と同時」「直前の動作の後」に当たるもの）: 次のどちらかで行います。
     - 下のステップを選んだまま、別の要素を選び、右のパネルの「ステップ k に足す」の「＋出す」などを押す。足した行の始まりで「前と同時」「前の後に」「前の始まりから○秒後」を選びます。
     - 別の要素を「新しいクリックで」足したあと、その最初の行の始まりで「前のステップと同じクリックにする」の「前と同時」などを選ぶ（前のステップにまとまります）。
   - **動かす・値・カメラなど**（動きの選び方の欄に、種類ごとにまとまっています）:
     - 動かす: 移動（今の位置からずらす／決めた位置へ）・拡大・縮小・回転（中心か決めた点のまわり）・左右反転・上下反転（要素の中心か、決めた線 x = 値・y = 値を境に裏返す）・色を変える・濃さを変える・
       線に沿って動く（今の位置から線の形に／線の上を）。右のパネルの「＋動かす」で足せます。
       **移動先は、キャンバスに薄い影（点線の枠と矢印）で示し、影をドラッグして決められます**（Shift で横か縦だけ）。数でも入れられます。
       影の位置は、そのステップより前の「移動」をたどった目安です（自由なコードの動きは数えません）。
       回転の中心を「決めた点」にすると、中心を十字の印で示し、ドラッグで決められます。
       ズームの「拡大する所を動かす」は、動く前の枠（点線）と移動先の枠を矢印で結んで示し、移動先の枠をドラッグで決められます。
     - 値: スライドの値（ValueTracker）を、決めた値（数か式）まで変える。
     - カメラ: 決めた点・要素の中心へ動かす、寄せる・引く、元に戻す。
     - 動画・音声: 再生・一時停止・停止・位置・音量・表示・非表示（動画・音声の要素を選んで「＋再生・操作」）。
       「そのあと」で、すぐ次の行へ・終わるまで待つ・決めた秒数だけ待つ、を選べます（待つ間も再生は続きます）。
       焼き込む動画・音声は、描いた時間しか進まず、クリックを待っている間は止まります。初めは「終わるまで待つ」にし、
       途中で音量を変える・隠すときは、例えば「再生（2 秒だけ待つ）→ 音量 0.3（終わるまで待つ）」のように、1 つのクリックの中に並べます
       （待たずに終わる行には、注意を出します）。焼き込むと、クリックした瞬間の再生位置に合わせた操作（クリックで音量を下げる・隠すなど）は
       できません（描画のときには、発表でいつクリックするか分からないため）。音量・表示などの行に、その注意と、前に終わりまで再生している
       ときの注意を出します。クリックの瞬間に合わせたいときは「発表で再生」にします。
     - ズーム: 出す・拡大する所を動かす・拡大率を変える・消す（ズームの要素を選んで「＋ズームの動き」）。
     - 線形変換: 行列で変換（線形変換の平面を選んで「＋行列で変換」）。
     - 動画・音声の操作、ズームを出す・消す、行列で変換は、前の動きが終わってから実行します（同じクリックの中で、時刻をずらせません）。
     - 同じ要素の「移動」と「拡大」などは、同時に（または途中から）重ねられます（`gui_stack` にまとめて書き出します）。
   - **変形・関数で変形・文字を打つ**（A3）:
     - 変形: 形を変える（置き換える。ReplacementTransform）・同じ形を合わせて変える（TransformMatchingShapes。式の変形向き）・
       フェードしながら変える・写しを変えて出す。「変えた先」に別の要素を選びます（変えた先は「スライド開始時に表示」を自動でオフにします）。
     - 関数で変形: 式で点を動かす（x・y の式）・時間で変わる式で動かす（Homotopy。x・y・t の式）・複素関数で写す（z の式）。
     - 1 文字ずつ打つ・1 文字ずつ消す（カーソルも付けられます）。
   - **要素の一部分だけを動かす**: テキスト・数式・表・行列・箇条書き・題名・コードは、行の「一部分…」を押すと、キャンバスに
     部品の枠と番号が出ます。押して選び（Shift で範囲）、「決める」を押します。「まとまり」で、1 段目（行など）か 2 段目（文字など）を
     選べます。コードでは `eq1[0][0:3]` のように書き出します。
     数式を少しずつ書く例: 数式を選んで「＋出す」（書く）→ 行の「一部分…」で前半の文字を選んで「決める」→ 右のパネルの「ステップ k に足す」の
     「＋出す」→ 2 つ目の行の「一部分…」で「前の行の残り」を押して「決める」（始まりは「前の後に」）。別々のクリックにするときは、
     2 つ目を「新しいクリックで」足します。
   - **動きを確かめる**（A4）:
     - 編集欄の「▷ このステップを試す」で、スライドを低い画質で描画し、そのステップ（クリック）の区切りから再生します（Ctrl+Enter と同じ小窓）。
     - 選んでいるステップの動きの道筋を、キャンバスに示します: 移動先の影、線に沿って動く道筋（点線と矢印）、回転の弧、
       カメラが動いたあとの映す枠（点線は動く前）、ズームの枠。カメラを「決めた点」へ動かす枠は、ドラッグで決められます。
   - 「出す」動きを足すと、その要素の「スライド開始時に表示」を自動でオフにします（出す前に見えていると、出す動きにならないため）。
   - 「コードにする」で、ステップをコードのステップに変えられます（動きの行は、そのコードになります。GUI には戻せません）。
   - **コードで書く**: 要素を選び、「＋ステップを追加」で、クリック 1 回分のコードを書きます（これまでと同じ）。
   - 要素を削除すると、その要素の動きの行も消えます（動きが無くなったステップは消えます）。「編集欄を隠す」で、編集欄をたためます。
   - クリックせずに続けて起きる動き（右へ動いてすぐ左へ戻る、など）は、1 つのステップに続けて書きます。
   - 別のクリックで動かすもの（出した要素を次のクリックで消す、など）は、別のステップにします。
   - スライド内のステップの順序は、キャンバスの下の一覧をドラッグして入れ替えます。
   - 「スライド開始時に表示」をオフにした要素は、キャンバス上で薄く表示されます。ステップのコード
     （例: `self.play(Write(eq))`）で出現させます。
3a. **編集を楽にする機能**:
   - **元に戻す・やり直す**: Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z）か、ツールバーの ↶ ↷。プロジェクト全体の変更を 100 回分まで覚えます
     （続けて打った文字・ドラッグは 1 回分にまとめます）。入力欄の中では、その欄の元に戻すが働きます。
   - **整列・等間隔**: 2 つ以上選ぶと、パネルの「整列」で左・左右中央・右・上・上下中央・下にそろえられます。3 つ以上なら、横・縦の
     間隔もそろえられます（グループは 1 つとして動かします）。1 つだけ選んでいるときは「スライドに揃える」で、スライドの端・中央へ。
     キャンバスの右クリックからも使えます。
   - **動きの行・ステップを写す**: 行の ⧉ で行を、編集欄の「⧉ ステップを写す」でステップを写し、「貼り付け」で足します。
     要素を 1 つ選んでいると「『○○』に替えて貼り付け」が出て、写した動きの対象を、選んだ要素に替えて貼り付けられます
     （コードのステップは、コードの中の変数名も替えます）。写したものは、別のスライド・別のプロジェクトにも貼り付けられます。
   - **テンプレート**:
     - 設定: 新規作成・プロジェクト設定の画面の「テンプレート」で選ぶと、背景色・フォント・文字サイズ・文字色・ページ番号など
       （と共通プリアンブル）を入れます。「今の設定を保存…」で保存します。
     - スライドの型: スライド一覧の「型」で、今のスライド（要素の配置と、選べばアニメーションも）を型として保存し、どのプロジェクトでも
       新しいスライドとして足せます。使っている画像・SVG・動画・音声も一緒に保存し、足すときにプロジェクトのフォルダへ写します。
     - 保存先は、アプリの設定フォルダ（Windows では %APPDATA%\ManimSlideGUI\templates）です。
4. **共通プリアンブル**: `\usepackage` や `\newcommand` を書きます。保存すると XeLaTeX でテスト描画し、
   エラーがあれば何行目かを示します。外部エディタで `preamble.tex` を編集したら「再読み込み」で取り込みます。
5. **描画・発表**: 保存と書き出しをしてから描画し、終わると `manim-slides present` の発表ウィンドウを開きます。
   エラーが出ると、下のパネルに「スライド2 / 要素 `eq` / ステップ3 / 5行目」のように位置を示し、
   該当するステップのコード欄の行をハイライトします。
6. **レイヤー（重なり順）**: 左下のレイヤー一覧は、上にあるものほど手前に描かれます。ドラッグで並べ替えるか、
   右のパネルの「重なり順」、キャンバスの右クリック、Ctrl+] / Ctrl+[（前面へ・背面へ）、
   Ctrl+Shift+] / Ctrl+Shift+[（最前面へ・最背面へ）で変えます。
   - ●（表示）を押すと、編集中だけ要素を隠せます。🔒（ロック）を押すと、キャンバスでは動かせず、クリックも
     後ろの要素に通り抜けます（レイヤー一覧からは選べます）。どちらも書き出しには影響しません。
   - 書き出す `.py` では、各要素に `gui_layer(要素, 順番)` で重なり順（z_index）を付けるので、ステップで後から
     出した要素も、レイヤーの順に重なります。コードで新しく作った物（z_index 0）は、GUI の要素より手前に描かれます。
7. **大きさと回転**: 要素を選ぶと、角に丸いハンドル、上に回転のハンドルが出ます。
   - 角のハンドルで拡大・縮小します（縦横比は保ちます）。テキストと数式は **文字サイズ（font_size）** が、画像は幅が変わります
     （形を引き伸ばすのではなく、その大きさで作り直すので、拡大してもぼやけません）。
   - 上のハンドルで回転します。Shift を押しながら回すと 15° 刻みです。右のパネルの「回転」で角度を入力することもできます
     （反時計回りが正で、Manim と同じ向き。「0° に戻す」もあります）。
   - 複数の要素やグループを選んでいるときは、まとめて拡大・縮小・回転できます（選んだ範囲の中心を軸に回り、
     それぞれの位置・角度・大きさが変わります）。
   - グループは向きを覚えていて、選ぶと選択枠もその向きで出ます。右のパネルの「回転」で角度を入力でき、
     「0° に戻す」で回す前の位置と向きに戻ります。グループでない複数選択も、選んでいる間は向きを覚えます。
   - 画像は、辺の中央のハンドルで横だけ・縦だけ伸び縮みできます（角のハンドルは縦横比を保ちます）。
     パネルの「縦横比を固定」をオフにすると、幅と高さを別々に入力できます。「元の縦横比」で元に戻せます。
   - 書き出す `.py` では `….move_to([x, y, 0]).rotate(30 * DEGREES)` になり、要素の中心を軸に回ります（キャンバスと同じ）。
   - スライドの周りには余白があり、はみ出した部分は薄く表示されます（描画では切れます）。端の近くの要素でも
     ハンドルをつかめます。
8. **コピー・貼り付け**: 選んだ要素を Ctrl+C でコピー、Ctrl+X で切り取り、Ctrl+V で貼り付け、Ctrl+D で複製します
   （右クリックのメニューからも）。グループごとコピーすると、グループとして貼り付けます。別のスライドや、
   別のプロジェクトにも貼り付けられます（別のプロジェクトの画像は、貼り付け先の images/ に取り込みます）。
   変数名は重ならないように付け直します。アニメーションのステップは貼り付けません（クリックの順番が変わるため）。
9. **複数選択とグループ**:
   - 空いている所からドラッグで範囲選択、Ctrl（または Shift）を押しながらクリックで選択に足す・外す、
     Ctrl+A ですべて選択、Esc で選択の解除です。レイヤー一覧でも Ctrl / Shift クリックで複数選べます。
   - 選んだ物は、ドラッグ・矢印キー（1px、Shift で 10px）・右のパネルの「中心」でまとめて動かせます。
     Delete でまとめて削除、重なり順の操作も選んだ物全体に効きます。
   - Ctrl+G（またはパネルの「グループ化」）でグループにし、Ctrl+Shift+G で解除します。グループの要素を
     クリックするとグループ全体が選ばれ、ダブルクリックすると中の要素を1つだけ選んで編集できます（Esc で戻る）。
   - グループは書き出す `.py` で `group1 = VGroup(要素, …)`（中の要素は重なり順、背面が先）になり、
     変数名で指定してステップから `self.play(FadeIn(group1))` のように動かせます。中の要素も、それぞれの
     変数名で今までどおり参照できます。グループの中のグループ（入れ子）には対応していません。
   - レイヤー一覧では、グループは1行にまとまり、中の要素が字下げされて並びます。グループの行をドラッグすると
     グループごと、中の要素をグループの外へドラッグするとグループから出せます。
10. **図形**: 「＋図形 ▾」のメニューは「基本図形」「線・注釈」「グラフ・座標」「表・数値・文字」「統計のグラフ」「定理・作図・計算」「3D」の 7 つのタブに分かれています（前回のタブを覚えます）。
   項目の下の小さな文字は、対応する Manim のクラス名などです。
   「＋図形 ▾」から、直線・矢印・両矢印・破線・長方形・正方形・角丸長方形・円・楕円・三角形・正六角形・星・
   円弧・扇形・点・吹き出し・中かっこ・数直線・座標軸・座標平面・表・ベクトル場などを置きます（全体の一覧は SPEC.md の 8.6）。見た目は、書き出しと同じ関数（`gui_shape`）で Manim が作った形です。
   - 線と矢印は、両端の丸をドラッグして動かします。ほかの要素の端・中心・辺の中点に吸い付きます
     （Alt を押している間は吸い付かない。Shift で 15° 刻み）。パネルで始点・終点の座標や矢じりも変えられます。
   - ほかの図形は、角のハンドルで拡大・縮小、上のハンドルで回転します。「縦横比を固定」をオフにすると、
     辺の中央のハンドルで横だけ・縦だけ伸ばせます。線の色・太さ（stroke_width）・不透明度・破線、塗りの色・不透明度も変えられます。
   - 書き出すと `circle1 = gui_shape("ellipse", ...)` のようになり、中身は Manim の Circle・Line（矢じり付き）・
     RoundedRectangle などです。ステップで `self.play(Create(circle1))` などが使えます。
11. **手書き・ベジェ曲線**: 「＋図形 ▾」の「手書き」「ベジェ曲線」で描きます（画面の上に操作の説明が出ます）。
   - 手書き: ドラッグで描き、なめらかなベジェ曲線にします。何筆描いても 1 つの要素になり、Enter（または Esc）で完成、
     Ctrl+Z で 1 筆戻します。パネルの「なめらかさ」で、あとから点の多さを変えられます。
   - ベジェ曲線: クリックで角の点、ドラッグで曲がる点（取っ手付き）を打ちます。最初の点をクリックすると閉じ、
     Enter かダブルクリックで完成、Backspace で 1 点戻します。ほかの要素の点に吸い付きます（Alt で吸い付かない）。
   - 点の編集: 曲線をダブルクリック（またはパネルの「点を編集」）。点・取っ手をドラッグで動かし（取っ手は反対側も
     同じ直線上に保つ。Alt で片方だけ）、点をダブルクリックで角／なめらかを切り替え、線の上をダブルクリックで点を追加、
     点を選んで Delete で削除します。Esc か Enter で終わります。
   - 線の色・太さ・破線、塗り（閉じた線や、手書きでも可）、拡大・縮小・回転は、ほかの図形と同じです。
   - 書き出すと `stroke1 = gui_shape("path", paths=[...])`（3 次ベジェ曲線の VMobject）になり、`Create(stroke1)` で
     描いた順に1筆ずつ描かれます。
12. **吹き出し**: 中身（テキスト・数式・画像など、いくつでも）を囲む枠で、中身に合わせて伸び縮みします。
   - 「＋図形 ▾」の「吹き出し」で、中にテキストが 1 つ入った吹き出しができます（吹き出しと中身はグループになります）。
     パネルの「中身」の「＋テキスト」「＋数式」で中身を足し、「外す」で外します。中身はダブルクリックで選んで自由に動かせます。
   - 既にある要素を選んで、右クリックの「吹き出しで囲む」（または複数選択のパネルのボタン）でも作れます。
     吹き出しと要素を選んで「吹き出しに入れる」で、中身を足せます。
   - 余白（左右・上下）・角丸・形（角丸・楕円）・尾の根元の幅を変えられます。尾の先（オレンジの丸）はドラッグで動かします。
     楕円の吹き出しは、中身と余白の箱の四隅を通る大きさにするので、中身がはみ出しません。
   - グループごと回すと、吹き出しも中身と一緒に回り、吹き出しの向きで中身を囲み直します。回した吹き出しに
     「＋テキスト」「＋数式」で足した中身も、同じ向きで、いまの中身の下に置きます。
   - 書き出すと `balloon1 = gui_balloon([text1, eq1], pad=(0.3, 0.2), ...)` になり、描画のときも、中身の実際の大きさから
     吹き出しの大きさを決めます。
13. **中かっこ・数直線・座標軸・座標平面・関数のグラフ**: 「＋図形 ▾」から置きます。
   - 中かっこ（Brace）: 要素を 1 つ選んでから追加すると、その要素に付きます（要素を動かす・大きさを変えると、かっこもついてきます）。
     何も選ばずに追加すると「2 点の間」のかっこになり、両端の丸をドラッグして動かします。パネルで上・下・左・右、
     間隔・とがり、かっこの先のラベル（数式またはテキスト。日本語も可）を変えられます。付けた要素を削除すると、
     かっこは「2 点の間」に変わって残ります。
   - 数直線（NumberLine）・座標軸（Axes）・座標平面（NumberPlane）: パネルで x・y の最小〜最大と目盛りの間隔、
     数字の有無と大きさ、矢印、軸のラベル（LaTeX。日本語は自動で `\text{…}` になります）、格子の色を変えます。
     角・辺のハンドルで軸の長さを変えます。軸ラベルは、キャンバスでラベルの上のオレンジの丸をドラッグすると好きな位置に
     動かせます（Shift で水平・垂直に。パネルの「ラベルの位置を戻す」で Manim の既定の位置に戻ります）。
   - 関数のグラフ: 座標軸（または座標平面）を選び、パネルの「＋グラフ」で追加します。式は **LaTeX** か **Python** で書きます。
     LaTeX は `\frac{1}{2}x^2 - 1`、`2\sin 2x`、`\sqrt{x}`、`e^{-x}`、`|x|`、`\log_2 x` など、よく使う書き方を
     Python（numpy）の式に変換し、変換した結果をパネルに表示します。Python では `x**2`、`np.sin(x)`、`sin(x)` などが使えます。
     x の範囲（空欄なら軸の端まで）も選べます。y が軸の範囲の外に出る所では線を切ります。グラフは座標軸と一緒に動き、
     座標軸を削除するとグラフも消えます。
   - 書き出すと `axes1 = gui_axes('axes', x_range=(-1, 5, 1), ...)`、`graph1 = gui_graph(axes1, "((x)**(2))/(4) - 1", ...)  # y = LaTeX の式`、
     `brace1 = gui_brace(target=eq1, direction=(0, -1), ...)` のようになります（中身は Axes・plot・Brace など）。中かっこの既定のアニメーションは `GrowFromCenter`、
     グラフは `Create` です。
13a. **行列・角・グラフの補助・曲線・極座標・複素平面**:
   - 行列: 「表・数値・文字」タブの「行列」（Manim の Matrix）。セルは表と同じく編集し（行・列の挿入・削除、貼り付け）、中身は LaTeX です。
     かっこ（[ ]・( )・| |（行列式）・{ }・なし）、文字の大きさ・色、成分どうしのすき間を変えられます（間隔は大きい成分に合わせて自動で決めます）。
   - 角・直角の印: 2 本の直線（矢印も可）を Ctrl で選び、「線・注釈」タブの「角（2 本の線）」「直角の印（2 本の線）」で付けます（Manim の Angle）。
     半径、どの角（4 つのうちどれか。ボタンに、今の線の向きで描いた扇形の図が出ます）、外側の角（180° を超える角）、点、ラベル（LaTeX）を変えられ、
     線を動かすと角もついてきます。線を消すと角も消えます。新しく付けた角は、初めから内側の角（三角形の頂点なら三角形の内側）になり、
     線を動かしても内側・外側の指定を保ちます（前の版で作った角が外側になっていれば、「点検」で知らせます）。
   - グラフの補助: グラフのパネルの「＋面積」「＋リーマン和」「＋接線」「＋割線」。面積は x の区間、リーマン和は区間・幅・高さを取る位置（左・中央・右）と色、
     接線は x と長さ、割線は x と Δx（Δx・Δy の線も）を決めます。グラフの式にスライドの値を使っていれば、値に合わせて変わります。
     区間・幅・x・Δx・長さには、数のほかにスライドの値を使った式も書けます（例: Δx に `h` と書き、ステップで
     `self.play(h.animate.set_value(0), run_time=3)` とすると、割線が接線に近づきます。Δx = 0 では接線の向きになります）。
   - 座標軸のパネルの「＋媒介変数曲線」で (x(t), y(t))、「＋陰関数」で x・y の式の曲線（例: `x^2 + y^2 = 4`）を加えます。
   - 「グラフ・座標」タブの「極座標の平面」（PolarPlane。半径の最大と目盛り、角度の目盛りの間隔、度か π の表示）と「複素平面」（ComplexPlane）。
     極座標の平面の「＋グラフ」は r = f(θ) のグラフ（LaTeX では `\theta`、Python では `theta`）になります。
     複素平面の「＋グラフ」は、y = f(x) か、複素数の曲線 z = f(t)（虚数単位は i。例: `e^{it}`、`\exp(ix)`、`\cos t + i\sin 2t`）を選べます。
13i. **動画・音声（発表で再生）**: ツールバーの「＋動画・音声」、またはキャンバスへのドラッグ＆ドロップ。
   - 取り込んだファイルはプロジェクトの `clips/` にコピーします（動画: mp4・mov・webm など、音声: mp3・wav・m4a・ogg・flac など）。
   - 動画はキャンバスでポスター（指定の時刻のコマ）を表示し、位置・大きさ（縦横比は元のまま）を決めます。音声はスピーカーのアイコンで示します
     （発表では何も表示しません）。パネルで試聴・試写できます。
   - 再生は、発表ウィンドウ（と Ctrl+Enter の試し描画）が Manim の映像の上に重ねて行います。描画の時間は増えず、元の画質のまま流れます。
     動画は Manim の要素より手前に出ます。
   - パネルの「再生」で「動画に焼き込む」を選ぶと、Manim の映像の中に動画のコマを描き、音声も入れます。重なり順はほかの要素と同じで、
     上に数式などを重ねられ、`video1.animate.shift(…)`・`FadeIn(video1)` などで動かせます（動かしている間・フェードの間は、
     Manim が更新を止めるので、コマも止まります）。音声は、描画のあとで全体の動画から切り分けて、各スライドの動画に入れ直すので、
     発表ウィンドウ・Ctrl+Enter の試し描画・ほかの環境（manim-slides の present、変換した HTML など）で鳴ります。描画は遅くなり、
     音声はクリックの区切りで止まります（スライドをまたぐ音声は「発表で再生」で）。焼き込むと、描いた時間の分しか動画・音声が進まないので、
     「自動」は終わるまで（くり返しなら 1 回分）待ってから次のクリックを受け付けます。ステップでは `wait=True` を付けるか、
     再生のあとにアニメーションや `self.wait(秒)` を置きます。
   - 設定（PowerPoint の「再生」タブに当たるもの）: 開始（自動＝スライドの初め／ステップで）、再生する区間、音量、フェードイン・アウト（音量）、
     くり返し、終わったら（最後のコマのまま・最初に戻す・隠す）、再生していないときは隠す、操作バー、ポスターの時刻、
     音声はスライドをまたいで再生（何枚目まで）。
   - ステップでの操作: `gui_media(self, video1, "play")`（ほかに `"pause"`・`"stop"`・`"seek", 12.5`・`"volume", 0.5`・`"show"`・`"hide"`）。
     `wait=True` で、終わるまで次のクリックを受け付けません。
   - 発表中: 次の区切りへ進んでも再生は続きます。戻る・一覧から飛ぶなどで移ったときは、移った区切りの始まりの時点の状態
     （再生中なら、その時点の位置から）にそろえます。動画にマウスを乗せると操作バー（再生・一時停止・シーク）が出ます。
     クリックはいつもどおり「次へ」です（操作バーの上を除く）。発表者用の情報ウィンドウの小さな画面と、ページ一覧の縮小画像には、動画は出ません。
13h. **座標軸なしの曲線・任意の曲線の接線・対数目盛り**:
   - 座標軸なしの曲線: 「グラフ・座標」タブの「関数のグラフ（FunctionGraph）」「媒介変数曲線（ParametricFunction）」「陰関数の曲線（ImplicitFunction）」。
     座標軸を使わず、画面の座標で描きます（要素の位置が原点 (0, 0)）。種類はパネルで切り替えられます。x・y（媒介変数は t）の範囲、
     1 の長さ（角のハンドルでも変わる）、向き（回転のハンドル）、線の色・太さ・破線・グラデーションを決めます。式にスライドの値を使えます。
   - 接線（TangentLine）: 線・図形・パス・グラフ・曲線を 1 つ選んでから「線・注釈」タブの「接線」。接点は、曲線の始点を 0、終点を 1 とした
     長さの割合（スライダーか数・式）で決めます。スライドの値を使うと、ステップで値を動かして接点を曲線に沿って動かせます。長さ・色・太さ・接点の点を選べます。
     曲線を動かす・形を変えると、接線もついてきます（曲線を消すと接線も消えます）。
   - 対数目盛り: 座標軸のパネルの「x 軸を対数目盛り」「y 軸を対数目盛り」（LogBase）。範囲・間隔は 10 の指数で書き（例: -1〜3 で 0.1〜1000）、
     目盛りの数字は 10^n の形です。グラフ・点・折れ線グラフ・グラフのラベルは値で書きます。面積・リーマン和・接線などのグラフの補助と、
     ベクトル場・媒介変数曲線・陰関数・ベクトルは、対数目盛りの座標軸では使えません（書き出しの前の検査で知らせます）。
13g. **要素の表・行列・ズーム・線形変換**:
   - 要素の表・行列（MobjectTable・MobjectMatrix）: 表・行列のパネルの「セルに要素を入れる」で、選んでいるセルにスライドのテキスト・数式・図形を
     入れます。要素を選んでから「表・数値・文字」タブの「要素の表」「要素の行列」を追加すると、選んだ要素を左上から順に入れた表を作ります。
     セルの要素の位置は表が決め（キャンバスでは動かせません）、表を動かすと一緒に動きます。要素の変数名はそのままなので、ステップで
     `Indicate(circle1)` のように個別に動かせます。「最初から出す」を外した要素は、セルの位置に置いたまま、あとのステップで `FadeIn(circle1)` などで出せます。
     要素を消すとセルは空になり、表を消すと要素はその場に残ります。要素を入れた表は回せません。
   - ズーム（ZoomedScene）: 「線・注釈」タブの「ズーム」。1 つのスライドに 1 つまで（2D のプロジェクトだけ）。四角が拡大を映す所で、
     オレンジの丸をドラッグすると拡大する所が動きます（キャンバスでも拡大して見せます）。拡大の倍率・枠の色と太さを決めます。
     「最初から出す」を外すと、ステップの `self.activate_zooming(animate=True)` で出します。ステップでは `self.zoomed_camera.frame`（拡大する所）・
     `self.zoomed_display`（映す所）を動かせます。ズームを使うと、書き出すクラスは `(Slide, ZoomedScene)` になります。
   - 線形変換の平面（LinearTransformationScene に当たるもの）: 「グラフ・座標」タブの「線形変換の平面」、または座標平面のパネルの「線形変換」で。
     変換の前の薄い方眼と、基底ベクトル î・ĵ を付けられます。ステップの `gui_apply_matrix(self, plane1, [[1, 1], [0, 1]], run_time=2)` で、
     平面と、平面に付いた要素（グラフ・点・ベクトルなど）と、パネルで選んだ要素をまとめて変換します（パネルの「＋変換のステップ」でも足せます）。
     変換は最初の平面の座標で考え、続けて変換すると行列の積の順に重なります。矢印は形を保ったまま、点・文字・数式は中心が動きます。
     平面の外に出た所は描かれないので、大きく変換するときは平面の範囲を広めにします。
13f. **グラフの追加分・数値の名前・軌跡・色が流れる枠・線のグラデーション**:
   - グラフ（y = f(x)）のパネルの「グラフの補助」に、「＋導関数」（plot_derivative_graph）・「＋原始関数」（plot_antiderivative_graph。
     F(0) の値を決める）・「＋ラベル」（get_graph_label。x の位置と置く向き）・「＋T字ラベル」（get_T_label。x 軸の上の三角と縦の線とラベル）を足しました。
     導関数・原始関数は、元のグラフの式を変えるとついてきます。破線・グラデーションも選べます。
   - 面積のパネルの「もう 1 つのグラフ」で、同じ座標軸のグラフを選ぶと、2 つのグラフの間を塗ります（get_area の bounded_graph）。
   - 折れ線グラフ（plot_line_graph）: 座標軸・座標平面を選んで「グラフ・座標」タブの「折れ線グラフ」か、座標軸のパネルの「＋折れ線グラフ」。
     点は 1 行に「x, y」で書き、点の印の有無・大きさ・色を選べます。
   - 数値（DecimalNumber）のパネルの「名前のラベル」に x などを書くと、「x = 1.00」の形になります（Manim の Variable と同じ形。
     ステップでは `num1.value`（数字）・`num1.label`（名前）、値に結び付けていれば `num1.tracker`）。
   - 軌跡（TracedPath）: たどる要素（点など）を選んでから「線・注釈」タブの「軌跡」。ステップでその要素を動かすと、通った跡が線で残ります。
     「消えるまで」の秒数を決めると、古い跡から消えます。キャンバスでは目印だけを出します。
   - 色が流れる枠（AnimatedBoundary）: テキスト・数式・図形を選んでから「線・注釈」タブの「色が流れる枠」。輪郭に沿って色が流れます
     （アニメーション・待ちの間。色は 2〜6 色、速さ・太さを変えられます）。
   - 線のグラデーション: 直線・パス・円弧・グラフ・媒介変数曲線・導関数/原始関数のパネルの「グラデーション」で、線に沿って色を変えます
     （2〜4 色。始点から終点へ）。
13e. **注釈・矢じりの形・ベクトル・角を丸める弧**:
   - 注釈（「線・注釈」タブ）: 付ける要素を 1 つ選んでから「囲み枠（SurroundingRectangle）」「背景の四角（BackgroundRectangle）」
     「下線（Underline）」「×印（Cross）」を選びます。要素の外接矩形に合わせて付き、要素を動かす・大きさを変えるとついてきます
     （要素を消すと注釈も消えます）。色・太さ・余白・角丸・塗り、×印の大きさ、背景の四角の色・不透明度を変えられます。
     背景の四角は要素のすぐ後ろに置きます。描画では作ったときの形のままです（アニメーションで要素を動かしても、注釈はついてきません）。
   - 円弧の中かっこ（ArcBrace）: 円弧（扇形）を選んでから追加します。外側・内側と、ラベル（数式）を選べます。
   - 矢じりの形: 線のパネルの「矢じり」で、三角（塗り・輪郭）・鋭い三角（Stealth）・丸・四角（塗り・輪郭）を選べます。
     「短い線では矢じりも小さく」で、Arrow と同じく、短い矢印の矢じりを線の長さに合わせて小さくします。
   - 形のラベル: 長方形・楕円・多角形・星・閉じた曲線のパネルの「ラベル」で、形の内側のいちばん広い所に数式を置きます
     （LabeledPolygram と同じ置き方。凹んだ形でも内側に置きます）。背景で下を隠す・枠で囲むも選べます。
   - 角を丸める弧（TangentialArc）: 2 本の真っすぐな線を選んでから追加します（角の印の「種類」でも切り替えられます）。半径と、どの角かを決めます。
   - ベクトル（Vector）: 「線・注釈」タブの「ベクトル」（Manim の単位）か、座標軸のパネルの「＋ベクトル」（座標軸の座標）。
     成分と始点は数か式で書け、スライドの値を使うと値に合わせて動きます。「先に成分を書く」で、矢印の先に縦の行列で成分を書きます。
13d. **グラフ（頂点と辺。Graph・DiGraph）**: 「グラフ・座標」タブの「グラフ（頂点と辺）」「有向グラフ」。
   - 頂点は表で（名前・色。名前は頂点の中に数式で書かれます）、辺は 1 行に 1 本「A B」のように書きます（有向グラフは左から右への向き）。
     頂点の名前を変えると、辺・位置もついてきます。頂点を消すと、その頂点の辺も消えます。
   - 配置は Manim（NetworkX）が自動で決めます: kamada_kawai（既定。辺の長さがそろう）・spring（ばねのつり合い）・circular（円周上）・
     shell（組ごとの同心円）・planar（辺が交わらない）・spectral・spiral・tree（木。根を選ぶ）・partite（組ごとの列。2 部グラフなど）・random。
     spring・random は「乱数の種」で毎回同じ配置にし（描画と同じ形）、「別の配置にする」で種を変えます。組は頂点の表の「組」の番号です。
     tree は木、planar は平面的なグラフでだけ使えます（使えないときは知らせます）。
   - 「この配置から手で動かす」で、今の自動の配置から、キャンバスの頂点の上のオレンジの丸をドラッグして頂点を動かせます。
   - 頂点は `graph1.vertices["A"]`、辺は `graph1.edges[("A", "B")]` で参照でき、`self.play(graph1.animate.change_layout("circular"))` で
     配置を変えるアニメーションもできます。頂点は辺の上に重ねて描きます。
13c. **標本空間（SampleSpace）**: 「表・数値・文字」タブの「標本空間」。四角を、確率の比で横（列）か縦（行）に分け、それぞれの区画を
   「分ける」でもう一方の向きに分けられます（ベイズの定理の図など）。区画ごとに確率・色・ラベル（数式）を決め、1 段目のラベルは中かっこを
   付けて外に、2 段目のラベルは区画の中に置きます（確率は合計が 1 になるようにそろえます）。題名、大きさ、枠の線、塗りの不透明度も変えられます。
   ステップのコードでは `space1.parts[0]`（1 段目の区画）、`space1.parts[0].subparts[0]`（2 段目）で区画を参照できます。
13b. **図形の追加分（円環・合成・ラベル付きの線と点など）と、コード・棒グラフ・LaTeX の文章**:
   - 「基本図形」タブ: 円環（Annulus）・扇形の円環（AnnularSector。開始・広がりの角度）、辺が弧の三角形（ArcPolygon。正多角形のパネルの
     「辺の膨らみ」で、どの正多角形でも辺を弧にできます。正三角形で 60° はルーローの三角形）、星形多角形（RegularPolygram。星のパネルの
     「描き方」で、輪郭の星と、頂点を結ぶ線の星を切り替え、いくつおきに結ぶかを決めます）、ラベル付きの点（LabeledDot）、輪の付いた点（AnnotationDot）。
   - 図形の合成: 2 つ以上の図形（長方形・円・多角形・星・扇形・点・曲線・円環・合成した図形）を Ctrl で選び、「合成: 和」「合成: 共通部分」「合成: 切り抜き」
     「合成: 重ならない部分」で作ります（Manim の Union・Intersection・Difference・Exclusion。切り抜きと重ならない部分は 2 つ）。
     元の図形は「初めから表示」がオフになり、キャンバスでは薄く表示されます。元の図形を動かす・形を変えると、合成した図形も作り直します。
     元の図形を消すと、合成した図形も消えます。破線の図形は合成に使えません（合成した図形を破線にできます）。
     描画では元の図形の位置から 1 度だけ作るので、元の図形をアニメーションで動かしても、合成した図形はついてきません。
   - 「線・注釈」タブ: 弧（ArcBetweenPoints）・曲がった矢印（CurvedArrow）は、線のパネルの「曲げる」の角度で、どの線・矢印も曲げられます
     （正で始点→終点の向きの右、負で左に膨らむ。キャンバスでは線の真ん中のオレンジの丸をドラッグしても曲げられます。曲げた線には角の印を付けられません）。ラベル付きの線・矢印（LabeledLine・LabeledArrow）は、線のパネルの
     「ラベル」で、どの線にも数式のラベルを付けられます（位置、大きさ・色、背景で線を隠す、枠）。Elbow（直角の印の単体。向きは回転で）。
     点のパネルにも「ラベル」（点の中に置き、収まるように点が大きくなります）と「輪」があります。ラベルはステップのコードで `line1.label` のように参照できます。
   - 「表・数値・文字」タブ:
     - コード（Code）: コード、言語、配色（Pygments のスタイル）、文字の大きさ・フォント、タブ幅、行番号、背景（角丸の四角・ウィンドウ）と色。
       明るい配色のときは、背景と文字の色を変えます。行は `code1.code_lines[0]` で参照できます。
     - 棒グラフ（BarChart）: 棒ごとの名前・値・色の表、縦軸（自動か、最小・最大・目盛り）、大きさ、棒の幅、軸の色、棒の上の値。
       名前は LaTeX の文章（数式は `$…$`）。値は `self.play(chart1.animate.change_bar_values([…]))` で変えられます。
     - LaTeX の文章（Tex）・題名（Title。下線付き。置くと Manim と同じく上の端に寄せます。「揃え」で左寄せ・中央・右寄せ。
       画面の幅の下線のときは下線の端に文字をそろえ、それ以外は画面の端から 1 単位の所に寄せます。複数行も左・右にそろいます）・箇条書き（BulletedList。1 行が 1 項目）。
       どれも LaTeX の文章として書き、数式は `$x^2$` のように `$` で囲みます。箇条書きは `list1[0]` で項目を参照し、
       `self.play(list1.animate.fade_all_but(1))` で 2 番目以外を薄くできます。
13j. **統計のグラフ**: 「＋図形 ▾」の「統計のグラフ」で置きます。どれも Manim の Axes の上に、点・線・棒・箱・扇形を描きます。
   - 種類: **散布図**（回帰直線・誤差棒）、**折れ線グラフ**（系列を重ねる。誤差棒）、**集合縦棒グラフ**（系列を横に並べる。誤差棒）、
     **積み上げ縦棒グラフ**、**ヒストグラム**（区間は自動（スタージェスの公式で数、幅はきりのよい数）・数を指定・幅を指定。度数か密度）、
     **箱ひげ図**（四分位数は教科書の求め方（中央値で前半・後半に分ける）が既定で、線形補間（Excel の QUARTILE.INC と同じ）も選べます。ひげは IQR の 1.5 倍まで（変えられます）。その外は外れ値として点）、**円グラフ**（割合・名前、ドーナツ、始まりの向き）。
     右のパネルの「グラフの種類」で、同じデータのまま種類を変えられます。
   - **横棒・帯グラフ**: 集合縦棒・積み上げ縦棒は「横向きにする」で横棒グラフになります（1 つ目の分類がいちばん上）。積み上げは
     「分類ごとに 100% にそろえる」で構成比のグラフになり、横向きと合わせると**帯グラフ**です（メニューの「帯グラフ（100% 積み上げ横棒）」、
     またはパネルの「帯グラフにする」ボタンで、まとめて設定できます）。「棒の中に値を書く」で、棒の中に値（100% のときは割合）を書きます
     （「入りきらない値は、棒の外に書く」がオンなら、細い棒の値は外に書きます。積み上げは引き出し線を付けて、横棒なら棒の上、
     縦棒なら棒の右に、重ならないように並べます。集合縦棒は棒の先に書きます。オフなら、入りきらない棒には書きません）。帯グラフ・横棒の凡例は、グラフの上に横に並べます。
     「グラフの中」の凡例は、点・棒・線に重ならない角に置き、どこも重なるときはグラフの外の右に出します。目盛りの数は 0 も書きます。
     ヒストグラムの区間の端は「以上・未満」（教科書）と「超・以下」（Excel の FREQUENCY・分析ツール）から選べます。
     データの表は 500 行・16 列までです（超えて貼り付けると知らせます）。1 列だけの「1,234」のような桁区切りや、全角の「１，５００」も数として読みます。
   - **データ**: 右のパネルの表で編集します（1 行目は見出しで、系列・箱の名前になります）。Enter で下のセルへ進み、最後の行で
     Enter を押すと行を足します。Excel などでコピーした範囲をセルに貼り付けると、そのセルから右下へ書き込みます。
     **行の並べ替え**: 行番号を押して行を選び（Shift で範囲、Ctrl・⌘ で 1 行ずつ追加）、行番号をつかんで上下にドラッグすると、
     選んだ行をまとめて、青い線の位置（行と行の間）へ移します。選んだ行は「↑」「↓」で 1 行ずつ動かしたり、まとめて消したりもできます
     （円グラフの各行の色も、行と一緒に動きます）。
     「CSV・表計算からの貼り付け」に CSV（カンマ・タブ・セミコロン・空白区切り）を貼って「表を置き換える」「下に足す」もできます。
     置き換えたときは、数の列を系列にし（見出しが「誤差」「SD」「SE」などの列は、すぐ左の系列の誤差にします）、軸の名前も見出しから付けます。
     数でないセル・空欄は飛ばします（全角の数字・桁区切りのカンマも読みます）。
   - **列の使い方**: 横軸（散布図・折れ線）または分類（縦棒）の列、系列（色・誤差の列・回帰直線）、値の列（ヒストグラム・円グラフ）、
     箱にする列（箱ひげ図）を選びます。回帰直線は最小二乗法で、式と決定係数 R² も書けます。
   - **軸**: 範囲は自動（きりのよい数）か手動。軸の名前（LaTeX の文章。日本語も可）、横の目盛り線。散布図などの軸は、範囲に 0 が
     あっても範囲の左下で交わります（縦棒グラフは 0 の所に横軸）。
   - **見た目**: 大きさ、点の大きさ、線の太さ、棒・箱の幅、塗りの不透明度、軸・文字の色、数字・名前の大きさ、凡例（グラフの中の空いている角・右・上・下・なし）、小数点以下の桁。
   - ステップのコードでは、`chart1.axes`（座標軸。`chart1.axes.plot(lambda x: …)` で関数を重ねられます）、`chart1.parts`
     （点・棒・箱・扇形をデータの順に）、`chart1.series`（系列ごと）、`chart1.fits`（回帰直線）、`chart1.errors`（誤差棒）、
     `chart1.legend`（凡例）を使えます。たとえば `self.play(LaggedStart(*[GrowFromEdge(b, DOWN) for b in chart1.parts]))`。
14. **表**: 「＋図形 ▾」の「表」で置きます（Manim の Table）。
   - セルは右のパネルで編集します。セルを選び（青い枠）、行の「上に挿入」「下に挿入」「削除」、列の「左に挿入」「右に挿入」
     「削除」で、その位置に行・列を足したり消したりします。Excel などでコピーした範囲を
     セルに貼り付けると、そのセルから右下へまとめて書き込みます（足りない行・列は増やします）。
   - セルの種類が「テキスト」のときは、`$x^2$` のように $ で囲んだセルだけが数式になります。「数式」にすると、
     すべてのセルを LaTeX で書きます（MathTable と同じ）。1 行目・1 列目を太字（見出し）にできます（テキストのセルだけ）。
   - 文字の大きさ・色・フォント、セルの間隔（h_buff・v_buff）、外枠の線、罫線の色・太さを変えられます。
     角のハンドルで拡大・縮小すると、文字の大きさと間隔をまとめて変えます。回転もできます。
   - 書き出すと `table1 = gui_table([["x", "0", ...], ...], ...)`（中身は Manim の Table）になります。
     既定のアニメーションは `self.play(table1.create())`（罫線を引いてから文字を書く）です。セルは
     `table1.get_entries((行, 列))`（1 始まり）、セルの背景は `table1.add_highlighted_cell((2, 3), color=YELLOW)` で扱えます。
15. **ベクトル場・流線**: 「＋図形 ▾」の「ベクトル場（矢印）」「ベクトル場（流線）」で置くか、座標軸・座標平面のパネルの
   「＋ベクトル場」「＋流線」で座標軸に重ねます（Manim の ArrowVectorField・StreamLines）。
   - 点 (x, y) でのベクトルの x 成分・y 成分を、グラフと同じく LaTeX か Python の式で書きます（例: `-y` と `x`）。
   - 座標軸に重ねたときは座標軸の座標で描き、座標軸と一緒に動きます。座標軸を消すと、同じ範囲・大きさの独立した
     ベクトル場になります。独立したものは、パネルで x・y の範囲と画面での大きさを決め、角・辺のハンドルで大きさを変えます。
   - 矢印の間隔（流線は始点の間隔）、矢印の長さ（上限あり＝Manim の既定・そろえる・比例）、流線の長さ、
     色（1 色、または大きさで青→緑→黄→赤に塗り分け）、線の太さ・不透明度を変えられます。
   - 流線の始点は Manim が乱数で少しずつずらしますが、乱数の種が固定なので、プレビューと描画は同じ形になります。
   - 書き出すと `field1 = gui_field('arrows', "-(y)", "x", axes=plane1, ...)` のようになります。既定のアニメーションは、
     矢印は `Create`、流線は `stream1.create()` です。流れ続けるアニメーションは `stream1.start_animation(warm_up=False, flow_speed=1.5)`
     のあとに `self.wait(3)` です（`end_animation()` で止めると、Manim の仕様で流線は消えます）。
16. **スライドの値（ValueTracker）・数値・座標の点**: 要素を選んでいないときのスライドのパネルの「値」で、そのスライドだけで
   使う数（名前と初めの値）を作ります。書き出すと、スライドの初めに `t = ValueTracker(0.5)` のようになります。
   - グラフ・ベクトル場の式に値の名前を書くと（例: `a x^2 - 1`）、値が変わるたびに描き直します（always_redraw と同じ）。
     LaTeX の式では、1 文字の名前はそのまま、`alpha` のような名前は `\alpha` と書きます。
   - 「＋図形 ▾ → 数値（DecimalNumber）」で、値（または固定の数）を表示します。小数点以下の桁数・符号・単位（日本語も可）を
     選べ、値に合わせて数字が変わります（左端の位置を保ちます）。
   - 座標軸のパネルの「＋点」で、座標軸の上の点を置きます。x・y を式で書き（例: x に `t`、y に `t^2`）、値に合わせて動きます。
     軸への点線（get_lines_to_point）も付けられます。
   - 値はステップで `self.play(t.animate.set_value(3), run_time=2)` のように動かします（値を使う要素のステップの既定）。
     キャンバスは初めの値で表示します。値の名前を変えると、そのスライドの式・ステップのコードの中の名前も変わります。
17. **カメラ**: 書き出す .py は `class Deck(Slide, MovingCameraScene)` になり、ステップで
   `self.play(self.camera.frame.animate.scale(0.5).move_to(eq1))` のようにカメラを動かせます。カメラは各スライドの初めに
   画面全体に戻ります。スライドのパネルの「カメラ」で、そのスライドの初めのカメラの位置（中心と幅）を決めることもでき、
   キャンバスにオレンジの点線の枠で表示します。
18. **3D**: 「プロジェクト設定」で「3D を使う」をオンにすると、3D の要素を置けます。書き出す .py は `class Deck(ThreeDSlide)` になります
   （この場合 `self.camera.frame` は使えません）。
   - 「＋図形 ▾」の「3D 球・立方体・直方体・円錐・円柱・トーラス」「3D 座標軸」「3D の点・線・矢印」で置きます。位置（x・y・z）・向き（x・y・z 軸の
     まわりの角度）・大きさ・色（市松模様も可）・不透明度・網目の線・細かさをパネルで決めます。キャンバスでドラッグすると、
     カメラから見た画面の向きに動き、角のハンドルで大きさが変わります。
   - 多面体: 「3D」タブの「正四面体・正八面体・正十二面体・正二十面体」（一辺の長さ）、「多面体（頂点と面）」（Polyhedron。頂点を 1 行に
     x, y, z、面を 1 行に頂点の番号で書きます）、「凸包」（ConvexHull3D。点を書くと、点をすべて含む凸の多面体を作ります）。
     面の色（2 色目で面ごとに交互）・不透明度、辺の色・太さ（0 で辺なし）、頂点の点を決めます。立体のパネルの「形」で、ほかの立体とも切り替えられます。
   - 3D 座標軸のパネルの「＋曲面 z = f(x, y)」で z = f(x, y) の曲面（LaTeX か Python の式、市松・1 色・高さで塗り分け）、
     「＋媒介変数曲面」で (x(u, v), y(u, v), z(u, v)) の曲面（Manim の Surface。u・v の範囲を決めます。球・トーラス・らせん面など）、「＋曲線」で
     (x(t), y(t), z(t)) の曲線、「＋点」「＋矢印」で座標軸の座標の点・矢印を加えます。式にはスライドの値も使えます。
     点・線・矢印の座標も、数のほかに式（例: `t`、`\cos t`）で書け、スライドの値に合わせて動きます（式を使った座標の物は、
     キャンバスのドラッグでは動かせません）。
   - スライドのパネルの「カメラ」で、そのスライドの初めのカメラの向き（φ: 真上からの傾き、θ: 水平の向き）・拡大率・中心を決めます
     （「真上」「斜め」などのボタンもあります）。カメラは各スライドの初めにこの向きに戻ります。ステップで
     `self.move_camera(phi=60 * DEGREES, theta=-30 * DEGREES, run_time=2)` や `self.begin_ambient_camera_rotation(rate=0.2)` を使います。
   - キャンバスの 3D の要素は、スライドの初めのカメラの向きから見た形を、Manim で描いた画像で表示します（1 つ 1〜数秒）。
     3D の物どうしの重なりは、描画ではすべての物の小さな面がカメラに近い順に重なります。キャンバスでも、既定ではスライドの 3D の物を
     まとめて 1 枚に描くので、食い込んだ物・曲面どうしも描画と同じに見えます（3D の物を変えるたびに、描き直しに数秒かかります）。
     プロジェクト設定の「キャンバスでの 3D の重なり」で、速い「奥行きの順」「レイヤーの順」にもできます。
   - **カメラのマウス操作**: キャンバスの上で、中ボタン（ホイール）を押したままドラッグで回す、Shift＋中ボタンのドラッグで中心を動かす、
     Ctrl＋ホイールで寄る・引く（スライドの初めのカメラ）。動かしている間は軸と立体の外形だけを描き、離すと描き直します。
     ステップの「カメラの向きを変える」の「キャンバスで決める」で、同じ操作でステップの向き・寄り方・中心を決められます
     （「カメラの向きを変える」には、中心 x・y の欄もあります）。
   - **描画の時間**: 3D の回転は 1 コマに時間がかかります。「ずっと回す」の 1 周を描くときは、描画を始めるときに長さを知らせます。
     確かめるときは「低」「中」、仕上げは「高（1080p・30fps）」も使えます。変えていないスライドの動きは、2 回目からは描き直しません。
   - テキスト・数式・2D の図形などは、既定で「画面に固定」（カメラを動かしても正面のまま。add_fixed_in_frame_mobjects）です。
     位置のパネルでオフにすると、空間の z = 0 の平面に置き、カメラと一緒に傾きます。
19b. **画像のトリミング・図形の形での切り抜き**（画像のパネル）:
   - **トリミング**: 「左・右・上・下」に、元の画像の端から切り落とす割合（%）を入れるか、「キャンバスで範囲を決める」で、元の画像全体を
     薄く出した上の青い四角をドラッグし、角・辺のハンドルで大きさを変えて「決定」（Enter で決定、Esc でやめる。Shift を押しながらで縦横比を保つ）。
     残した部分は今の位置のまま残り、大きさの「元の大きさ」「元の縦横比」は残した部分のものになります。元の画像のファイルは書き換えません
     （書き出すコードの gui_image(…, crop=(左, 上, 右, 下)) で切り出します）。回転した画像は数値で指定します。
   - **図形の形で切り抜く**: 同じスライドの要素（図形・手書き・ベジェ曲線・文字・数式など）を選ぶと、その形と重なる所だけを見せます（共通部分）。
     「形の外側を残す」で、形の所をくり抜けます。輪郭が重なる所は穴になります（「A」「O」の文字の穴など）。開いた線は始めと終わりを結んだ形にします。
     今の画像と型の位置で、画像の透明度に焼き込むので（gui_image_mask）、あとで画像を動かすと、切り抜いた形のまま動きます。
     型の要素はふつうの要素として残るので、見せたくないときは「型の要素を最初は出さない」を押します。キャンバスでも、切り抜いた形で表示します
     （型を動かすと、切り抜きも合わせて変わります）。
19. **画像**: 「＋画像」でファイルを選ぶか、画像のファイルをキャンバスにドラッグ＆ドロップ（落とした位置に置く）、
   またはコピーした画像を Ctrl+V で貼り付けます。PNG・JPEG・GIF・WebP・BMP・TIFF に対応しています（PDF は不可）。
   - SVG（.svg・.svgz）も同じ方法で取り込めます。SVG は Manim の SVGMobject で図形として描くので、拡大してもぼやけません。
     パネルで大きさ（縦横比の固定・解除）、色（元の色・1 色にする）、線の色・太さをそろえる、不透明度を変えられ、回転もできます。
     書き出すと `svg1 = gui_svg("images/名前.svg", width=…)` になります。SVG の中の文字（text）と埋め込み画像は表示されず、
     グラデーションは単色になります（取り込むときに知らせます。文字はアウトライン化してから保存してください）。
   - 画像はプロジェクトの `images/` にコピーされ（同じ内容の画像は1つにまとめます）、書き出す `.py` では
     `gui_image("images/名前.png", width=…)`（中身は `ImageMobject`）として、`.py` のフォルダからの相対パスで読み込みます。
     プロジェクトのフォルダごと移動しても動きます。
   - 大きさは右のパネルの「幅」「高さ」（縦横比は固定）、「元の大きさ」（1 画素 = 1080p の 1 画素。Manim の既定と同じ）、
     「画面の幅」「画面の高さ」で変えます。不透明度と、拡大時に画素をぼかさない設定（ドット絵向け）もあります。
     「差し替え…」で、位置と幅を保ったまま別の画像に替えられます。
   - 数式を `\\` で改行したときの行の揃え方は、数式のパネルの「複数行の揃え」（左・中央・右、既定は中央）で選びます。
     & を書いた数式は、& の位置で揃います。
   - 写真の回転情報（EXIF）は取り込むときに画素に反映し、動く画像（アニメーション GIF など）は、置くときに「動かす」か「最初のコマだけ」かを聞きます
     （最初のコマだけにするのは、Manim の ImageMobject と見た目をそろえるため）。
     - 「動かす」にすると、音の無い動画にして、スライドの初めからくり返し再生する動画の要素として置きます（発表ウィンドウ・試し描画・HTML で動きます。PowerPoint はクリックで再生、PDF は 1 コマ）。透明な部分はスライドの背景色で塗ります。
   - アニメーションは `FadeIn`・`FadeOut`・`GrowFromCenter`・`img1.animate.shift(…)` などを使います。
     `Write`・`Create` は画像には使えず、`Indicate` は画像全体が単色になります。画像を含むグループは `Group` になります。
   - 描画のときは、画像を描画の解像度で必要な大きさ（拡大のアニメーション用に 1.5 倍の余裕）まで縮めてから使います。
     画像が動く・現れる・消える間は、1 コマごとに画像を変形するため、テキストより描画に時間がかかります
     （1080p で、画像の動き 1 秒あたり数秒が目安）。確認のときは「中（720p）」などの低い品質が速いです。
   - `images/` に残っている、どこからも使われていない画像は、描画には影響しません。
   - 画像のファイルが見つからないときは、キャンバスに赤い点線の枠を出し、書き出しの前の検査でも知らせます。
18a. **ページ番号**: 「プロジェクト設定」の「ページ番号」で、付けるかどうか、位置（右下・下の中央・左下・右上・上の中央・左上）、
   書き方（「3」か「3 / 10」）、大きさ、色を決めます（文字は既定のフォント）。スライドのパネル（要素を選んでいないとき）の「ページ番号」で、
   スライドごとに「プロジェクトの設定に従う・付ける・付けない」を選び、「番号を指定する」で番号を変えられます。
   - 番号はスライドの順に 1, 2, 3, …。あるスライドで番号を指定すると、次のスライドからはその続きになります（「3 / 10」の 10 は最後のスライドの番号）。
     付けないスライドも、番号は数えます。
   - キャンバスでは、書き出しと同じ形で表示します（選べません）。2D ではカメラの枠について動き、スライドの初めのカメラの位置を決めたり、
     ステップでカメラを動かしたりしても、画面の同じ隅に同じ大きさで出ます。3D では画面に固定します。
   - ステップのコードでは `self.page_number` で参照できます（例: `self.play(FadeOut(self.page_number))`）。「このスライドを試す」でも、全体の番号で出ます。
19a. **このスライドを試す（実描画プレビュー）**: ツールバーの「▷ このスライドを試す」で、編集中のスライドだけを低画質（480p）で描画し、
   キャンバスの上の小窓で再生します（数秒〜十数秒）。発表と同じく、クリックの区切りごとに「次へ ▶」（→・Space・動画のクリック）と
   「◀ 前へ」（←）で進め、「⟲」（R）でその区切りをもう一度、「通しで再生」でスライドの初めから最後まで続けて再生します。
   下の「初め・1・2…」のボタンで、好きな区切りへ移れます。小窓は上の帯をドラッグして動かし、右下の角で大きさを変えられ、Esc で閉じます。
   「描画し直す」で、直したあとにもう一度描画します。エラーは、ふつうの描画と同じく下のパネルに出て、該当のスライド・要素・ステップへ移れます。
   - 試し描画は、発表用とは別のクラス名（`GuiSlidePreview`）で描くので、発表用の描画結果（`slides/Deck.json` など）は変わりません。
     プロジェクトのフォルダに `GuiSlidePreview.py`、`slides/` に `GuiSlidePreview.json` などができます（消しても構いません）。
   - **再生の操作**: 「⏸／▶」（K）で一時停止・再生、シークバーで好きな時刻へ（「通しで再生」の間はスライド全体のバーになり、区切りの所に目盛りが付きます）、
     速さ（0.25〜2 倍）、「⏮」「⏭」（,・.）で 1 コマずつ戻る・進む（一時停止になります）。「発表で再生」の動画・音声も、時刻と速さに合わせます。
   - **動きの欄と連動**（初めはオン）: 小窓で見ている区切りのステップを、画面の下の動きの欄で開きます。逆に、動きの欄でステップを選ぶと、小窓がその区切りへ飛びます。
     速さと連動のオン・オフは、このブラウザに覚えます。
20. **発表ウィンドウの操作**: 左クリックまたは → キーで次へ、右クリックまたは ← キーで前へ進みます。
   そのほか、F で全画面、Space で一時停止、R でもう一度再生、Q で終了です（manim-slides のキー操作）。
   発表ウィンドウは同時に1組だけ開きます。開いている間に「発表のみ」を押しても、新しくは開きません。
   描画し直したときは、古い内容のウィンドウを閉じてから開き直します。
   - **開き方**: 上のツールバー「発表を開く」の右の選択欄で、「最大化で開く」（既定）「フルスクリーンで開く」
     「通常の大きさで開く」を選べます。選んだ内容はこのパソコンのユーザー設定に保存され、次回以降も使われます
     （プロジェクトごとではありません）。変更は次に発表ウィンドウを開くときから反映されます。
   - どの開き方でも、発表中に F キーでフルスクリーンと通常表示を切り替えられます。
   - 画面が2つあり、発表者用の情報ウィンドウが出る場合は、フルスクリーンのときに情報ウィンドウもフルスクリーンになります
     （manim-slides の動作）。「最大化で開く」のときは、別の画面にある情報ウィンドウも最大化します。
   - **発表者用の情報ウィンドウ**: ツールバーの「発表者用」の選択欄で、「画面が2つなら表示」（既定。manim-slides の動作）
     「常に表示」「表示しない」を選べます。情報ウィンドウには、manim-slides の「現在・次のスライド」に加えて、次のものを出します。
     - **フルスクリーンの切り替えボタン**と、キー操作の説明（F でフルスクリーン切り替えなど）。
     - **全ページの一覧**: クリックの区切りごとに、その区切りの最後の画面を縮小して並べます。見出しは「ページ 2」（ページの始め）、
       「2-1」（ページ 2 の 1 回目のクリック）のように付きます。押すと、発表ウィンドウと情報ウィンドウの両方がその位置へ移り、
       その区切りのアニメーションを再生します（→ キーでそこに来たときと同じ）。今の位置は一覧で選ばれた状態になります。
     - 縮小画像は発表ウィンドウを開いたあとに裏で作り、`slides/gui_pages/thumbs` に残して次回から使います。
       見出しの番号は、描画のときに `slides/gui_pages/<クラス名>.json` に記録されます（このアプリで描画し直す前の結果では、通し番号になります）。
     - 一覧やボタンのクリックは発表を進めません。それ以外の場所のクリックは、これまでどおり「次へ」「前へ」です。
   - **発表の道具**（発表ウィンドウ・情報ウィンドウのどちらでキーを押しても使えます。? キーで一覧を画面に出せます）:
     - **L: レーザーポインター** — マウスに付いて動く赤い点（矢印のカーソルは隠れます）。もう一度 L で消します。
     - **P: ペン** — ドラッグで画面に書きます（その間、クリックで次へは進みません）。右クリックで最後の 1 本を消し、
       C で色（赤・青・緑・黄・黒・白）を変え、E でそのページの線を全部消します。もう一度 P でペンを終えます（書いた線は残ります）。
       **[ ]** で太さ、**M** で蛍光ペン（太い半透明の線）、**Shift** を押しながらドラッグで直線、**Ctrl** を押しながらドラッグで四角。
       書いた線はページごとに覚え、ページを移ると消え、そのページに戻るとまた出ます。白画面（W）の上にも書けます（黒板のように使えます）。
     - **B: 黒画面 ／ W: 白画面** — 画面を真っ黒・真っ白にします（重ねて再生する動画も隠します）。もう一度押すと戻ります。
     - **Z: 拡大鏡** — マウスの周りを丸く拡大します（+ − で 1.25〜6 倍）。
     - **数字と Enter: そのページへ飛ぶ** — 「3」Enter でページ 3 の初めへ、「3-2」（または 3.2）Enter で、ページ 3 の 2 回目のクリックの所へ。
       「A2」Enter で付録の 2 ページ目へ。
       打っている番号は画面の左下に出ます（Backspace で 1 文字消す、Esc でやめる）。
     - **Esc** — 道具（レーザー・ペン・拡大鏡・黒白画面・番号の入力）をまとめてやめます。
     - 書き込み・レーザー・拡大鏡は、発表者用の情報ウィンドウの小さな画面にも同じように映ります。重ねて再生する動画（発表で再生）の上には描きません。
     - **タイマー**: 情報ウィンドウの操作欄に、経過時間と時刻を出します。最初のページから進んだときに計り始め、「一時停止」「リセット」ができます。
       「目安」に発表の時間（分）を入れると残り時間も出し、残り 2 分で橙、過ぎると赤になります。
19c. **動きの追加分（段階M）**: 画面の下の動きの行の「動き」で選べます（要素のパネルのボタンからも足せます）。
   - **出す**: 「部品を少しずつずらして出す」（LaggedStart。フェード・下から伸ばす・中心から大きく・線を描く・書く、ずらす割合。
     統計のグラフは座標軸を先に出してから点・棒などを順に出します。統計のグラフの「＋出す」は、これになります）、
     「1 語ずつ出す」（空白・改行で区切った語ごと。日本語のように空白の無い文は行ごと。カーソルも付けられます）。
   - **強調**: 「線を描いてから消える」（要素の写しを線で描いて、フェードで消す。古い Manim の ShowCreationThenFadeOut と同じ動き）。
   - **変形**: 「位置を入れ替える」（Swap。2 つの要素の位置を弧を描いて入れ替える）。
   - **関数で変形**: 「行列で変換」（ApplyMatrix。要素の点を [[a, b], [c, d]] で変換。基準は要素の中心か原点）。
   - **要素ごとの動き**（その種類の要素にだけ使えます。ほかの要素では選べません）:
     「棒の値を変える」（棒グラフ。change_bar_values。棒の数だけ値を書きます。数が合わないと書き出し前の検査で知らせます）、
     「グラフの並びを変える」（頂点と辺のグラフ。change_layout）、「行に色の帯を付ける」（コード。「2」「2-4」「1, 3」の行に帯。
     次の帯でその行へ動き、空にすると消えます。帯は背景と文字の間に入ります）、「数を数えながら変える」（数値。ChangeDecimalToValue。
     スライドの値を表す数値は、その値を変えます。同じ値を使うグラフなども一緒に動きます）。要素のパネルには「＋棒の値を変える」などのボタンが出ます。
   - **ずっと動かす**（updater）: 「ずっと回す」（度/秒。中心は要素か決めた点）、「進め続ける」（単位/秒。下記）、「ほかの要素について行く」
     （今の位置の差を保つ）、「ずっと動かすのをやめる」。前の動きが終わったところで付け外しします。
     「ずっと回す」（と 3D の「カメラをずっと回す」）は、クリックを待つ間も回り続けます: そのステップの動きのあとに、ちょうど 1 周
     （回すものが複数なら、全部がそろって元に戻る長さ。60 秒まで）の区切りを足して、クリックまでくり返します（切れ目は出ません。
     この区切りはクリックの数に入れません）。「やめる」までの後のステップでも同じです。ステップが「くり返す」「終わったら自動で次へ」の
     ときは足しません。
     「進め続ける」は「クリックを待つ間」を選べます。「進み続ける（画面の外へ出たら反対側から戻る）」（初めの設定）なら、要素が画面の外へ
     出きったところで、同じ線を逆にたどった画面の反対側から入ってきて、同じ向きに進み続けます（斜めも可。画面を 1 回通り抜ける時間で
     ちょうど元に戻るので、クリックを待つ間も切れ目なくくり返せます）。「止める」なら、ほかの動き・「待つ」の間だけ進み、クリックを
     待つ間はその位置で止まります。「ほかの要素について行く」は、ついて行く先が動いていれば、クリックを待つ間も一緒に動きます。
     回すもの・進むものが複数あるときのくり返しの長さは、全部がそろって元に戻る長さ（60 秒まで。そろわないときは、いちばん長いもの）です。
   - **値**: 「値を増やす・減らす」（increment_value。今の値から決めた分だけ）。
   - **3D のカメラ**（3D のプロジェクトだけ。2D では「カメラ」の動きを使います）: 「カメラの向きを変える」（move_camera。φ・θ（度）・寄り方。
     空欄は今のまま）、「カメラをずっと回す」（begin_ambient_camera_rotation。横か縦、度/秒）、「カメラを回すのをやめる」。
19d. **数式の一部の色・対応を決めて変える・元の状態に戻す・速さの変化・流れに沿って動かす（段階A）**:
   - **数式の一部の色**（数式のパネルの「一部の色」。Manim の `tex_to_color_map` と同じ）: 「＋ 色を付ける文字」で、色を付ける文字
     （LaTeX の書き方。例: `x`・`\pi`・`x^2`・`\frac{1}{2}`）と色を決めると、数式の中の同じ文字すべてに色が付きます。
     LaTeX の欄で文字を選んでから「LaTeX で選んだ文字を足す」でも足せます。空白は無視して探し、長い文字を先に探します
     （`x` と `2x` を決めると、`2x` の所は `2x` の色）。それぞれの横に、見つかった数が出ます。
     書き出しでは、見つかった所を `{\color[HTML]{…} …}`（xcolor）で囲みます（キャンバスの仮表示も同じ色になります）。
     色・環境の名前などの引数の中（`\begin{…}`・`\hspace{…}` など）、`\left(` の `(`、`^`・`_` やコマンドのすぐ後に続く 2 文字以上
     （`\frac12` の `12` など。囲むと意味が変わる所）は探しません。中かっこの対が合わない文字・`&`・`\\` を含む文字は使えません。
     LaTeX の中に自分で `\textcolor{red}{x}` などと書いても色が付きます（xcolor は、共通プリアンブルのあとに自動で読み込みます）。
   - **対応を決めて変える**（「変形」の動き。TransformMatchingTex の、対応を手で決める版）: 「変えた先」を選び、「＋ 対応を足す」を押すと、
     ① 対象の部品 → ② 変えた先の部品の順に、キャンバスで選べます（選ぶ要素だけがはっきり見え、ほかの要素は薄くなります。ほかの対応で
     選んだ部品には ✓ が付きます）。選んだ部品どうしがなめらかに変わります。決めなかった部品は「残り」で、同じ形の文字どうしを合わせる
     （TransformMatchingShapes と同じ）か、フェードで入れ替えます。移項（`x+2=5` → `x=5-2` で `+` → `-`、`2` → `2`）や、
     約分・展開を見せるのに向きます。対象・変えた先を変えると、決めた対応は消えます。数式を書き換えたら、対応を選び直してください。
   - **今の状態を覚える・覚えた状態に戻す**（「動かす」の動き。save_state・Restore）: 「覚えた状態に戻す」で、動かす・大きさ・回す・
     色などをまとめて、なめらかに元に戻します。戻り先は、前の「今の状態を覚える」の状態（無ければスライドの初めの状態）です。
     どちらも要素全体（またはグループ）に使います（一部分には使えません）。
   - **速さの変化**（動きの行の「時間」「緩急」の横。Manim の `ChangeSpeed` と同じ速さの変え方）: 動きの途中で速さを変えます。
     「途中でゆっくり」「だんだん速く」「だんだん遅く」「途中で止まりかける」か、「自分で決める…」で `0:1, 0.5:0.2, 1:1` のように
     「進み（動きの割合 0〜1）:速さ（倍率。1 がそのまま、0.2 は 5 分の 1）」を並べます。間は、なめらかにつなぎます。
     遅くした分だけ動きは長くなり、その長さが横に出ます（「前の後に」の行は、その長さのあとに始まります）。緩急は、速さを変えた進みに掛かります。
     「前の動きの後に」実行する動き（ずっと動かす・動画の操作など）には付けられません。
   - **流れに沿って動かす**（「動かす」の動き。Manim の `PhaseFlow`）: ベクトル場の流れ（矢印の向きと大きさ）に乗せて動かします。
     「流れ」で、スライドのベクトル場（矢印・流線）の要素を選ぶか、速度の式（画面の座標 x・y で、1 秒あたりの動き。例: 回る流れは
     x の速さ `-y`、y の速さ `x`）を書きます。「流れる時間」が長いほど遠くまで流れます（動きの時間とは別で、動きの時間の間に、
     その時間だけ流れます。例: 回る流れで 3.14 なら半周）。「形を保つ」は中心の流れに合わせて動かし、「点ごとに流す」は形の点を
     1 つずつ流します（形が流れで伸び縮みします）。緩急の既定は「一定の速さ」です。
19e. **描画するスライドの選択**:
   - **描画しないスライド**（いつも）: スライドの一覧でスライドにマウスを乗せて「描画しない」を押すか、スライドのパネルの「発表」の
     「このスライドを描画しない」で印を付けます。印の付いたスライドは一覧で薄く表示され、「描画しない」の印が出ます。プロジェクトに保存されます。
   - **今回だけ描画するスライド**: ツールバーの「描画: …」で選びます。「印の通り」（既定。描画しない印のスライドを除く）・「このスライドだけ」・
     「選んで描画…」（チェックしたスライドだけ。ダイアログで、それぞれのスライドが何ページになるかも出ます）。今回だけの選択は保存されません。
   - **ページ番号**: 描画するスライドだけで、詰めて付け直します（スライド 3 を描画しなければ 1, 2, 3(元の 4) …）。「n / N」の N も、
     描画する枚数になります。番号を指定したスライドからは、その続きの番号になります。
   - **切り替え効果**: 描画しないスライドの次のスライドは、その前に描画するスライドの最後の画面から切り替わります（描画するスライドの
     最初になったスライドには付きません）。
   - **試し描画・発表・ファイルへの出力**: 描画しないスライドも、編集と 1 枚だけの試し描画（▷試す）はできます（ページ番号は、もし描画したら
     の番号）。発表・ファイルへの出力は描画した結果から作るので、描画しなかったスライドは入りません（出力の画面に、何枚を描画したかが出ます）。
   - 描画しないスライドの、書き出し前の検査の問題（未入力など）では、描画を止めません。
19f. **発表の録画**: 発表しながら録画し、あとで 1 本の動画（mp4）にします。
   - **録る**: 発表ウィンドウで **Ctrl+R** を押すと録画を始めます。もう一度押すと一時停止、さらに押すと再開します（止めている間は録画に
     入りません）。**Ctrl+Shift+R** で録画を終えます。発表ウィンドウを閉じても終わります。発表者用の情報ウィンドウにも同じボタンと、
     録画の時間（● 録画中 3:21）が出ます。1 回の発表の中で、何本でも録れます。
   - **録画に入るもの**: 映したスライドの動き（戻る・飛ぶ・くり返し・一時停止もそのとおり）、ペン・レーザーポインター・拡大鏡・黒白画面、
     重ねて再生した動画（発表で再生）、スライドの音（効果音・BGM・発表で再生する動画や音声）、マイクの声、カメラの小窓。
     ページ番号の入力やキーの一覧など、発表者だけに向けた表示は入りません。
   - **作り方**: 発表中は画面を撮らず、何をいつ映したかと、マイク・カメラだけを記録します（発表が重くならず、画質は描画した動画のまま）。
     録画を終えると、操作アプリが自動で動画に組み立てます（「● 録画」の画面に進み具合が出ます。動きの多い 1080p の部分で、録画の長さの
     半分〜同じくらいの時間がかかります。動きの少ない部分は速く進みます）。
   - **● 録画（ツールバー）**: マイク・カメラの「使う・使わない」と機器の選択（次に発表ウィンドウを開いたときから使います）、
     動画にするときの設定（カメラの小窓の位置（四隅）・大きさ（小・中・大）・角を丸める、スライドの音の有無と音量、マイクの音量）、
     録画した動画の一覧（▶ 見る・場所を開く・動画にし直す・元の記録を消す・削除）。動画にするときの設定は、録ったあとでも
     「動画にし直す」で変えられます。
   - **保存先**: プロジェクトの `recordings/<クラス名>_<日時>.mp4`。元の記録（発表の記録・マイクやカメラの録音・使った動画へのリンク）は
     `recordings/.raw/` に残します（描画し直しても、動画にし直せます）。要らなくなったら「元の記録を消す」で動画だけを残せます。
   - 発表ウィンドウが途中で落ちた場合も、記録が残っている所までを動画にします。
   - Windows では、初めてマイク・カメラを使うときに、「設定 → プライバシーとセキュリティ → マイク／カメラ」で、デスクトップアプリの
     利用を許可しておく必要があります（許可していないと、録画は無音・カメラなしになります）。
19g. **自動保存とバックアップ**（どちらも初めはオン。ツールバーの「バックアップ」で、オン・オフと間隔を変えられます）
   - **自動保存**: 変更が止まって 3 秒（2・3・5・10・30 秒から選べます）たったら、「保存」と同じく `project.json` に保存します。
     変え続けていても、最初の変更から 30 秒たったら保存します。ドラッグしている間は待ちます。下の欄に「自動保存しました（19:20）」と出ます。
     オフにすると、今までどおり「保存」（Ctrl+S）を押したときだけ保存します。
   - **バックアップ**: プロジェクトの `backups` フォルダに、スライドの内容とプリアンブルを、日時の付いたファイルで残します
     （画像・動画のファイルは含みません）。次のときに作ります。
     - 保存（自動保存も）したとき、前のバックアップから 10 分（5・10・15・30・60 分から選べます）過ぎていれば
     - プロジェクトを開いたとき（前の作業の終わりの状態）
     - バックアップから戻す直前（戻したのを取り消せるように）
     - 「今の状態を控える」を押したとき（メモを付けられます。自動では消しません）
     直前のバックアップと内容が同じなら作りません。自動で作ったものは、新しい 20 個と、それより古いものは 1 日 1 個（その日の最後）を
     30 日分残し、それより古いものは消します。
   - **戻す**: 「バックアップ」の一覧で、日時・作った理由（自動・開いたとき・戻す前・手動）・メモ・スライドと要素の数を見て
     「この状態に戻す」を押します。今と同じ内容のものには「今と同じ内容」と出ます。
   - 設定は、このパソコンのすべてのプロジェクトに使います。
19h. **1 本の動画として書き出す**: 「ファイルに出力…」で「動画（mp4）」を選ぶと、直前に描画した結果を、クリックせずに最後まで流した
   1 本の動画にします（`export/<クラス名>.mp4`）。
   - **待ち時間**: クリックの区切りでは、出力の画面で決めた秒数（既定 2 秒。前回の値を覚えます）だけ待って進みます。
     ステップの欄の「動画での待ち」と、スライドのパネルの「発表」の「動画での待ち」（初めの表示のあと）で、場所ごとに秒数を変えられます
     （空欄なら全体の秒数）。場所ごとの秒数は、それを付けたあとに一度描画し直すと使われます（描画のときに、区切りとステップの対応を記録するため）。
   - 「終わったら自動で次へ」の区切りは待たずに進みます。「くり返す」の区切り（「ずっと回す」の待ちも）は、待つ間くり返し、
     くり返しの切れ目で次へ進みます（少なくとも 1 回は流します）。最後の区切りのあとも、同じだけ待ちます。
   - スライドの音と、「発表で再生」の動画・音声（ステップの時刻どおりの再生・停止・音量・フェード）も入ります。
     ペンなどの書き込みや声を入れたいときは、「● 録画」で発表を録画してください（組み立ては録画と同じ仕組みです）。
   - **字幕**: 「発表者ノートを字幕ファイル（.srt）にする」を付けると、その区切りを映している間のノートを、動画と同じ名前の `.srt` にします
     （動画には焼き込みません。再生ソフトや動画サイトで表示・非表示を切り替えられます）。「字幕の中身」で次のどちらかを選べます。
     - **スライドのノートと、ステップのノートを続けて**: 発表ウィンドウのノートと同じ中身から、「【クリック n】」の見出しを外したもの
     - **ステップのノートだけ**: ステップを映している間はそのステップのノートだけ。ステップのノートが無い所（スライドの初めの表示など）は、スライドのノート
     字幕は読みやすく整えます: Markdown の飾り（見出しの #・太字・箇条書きの記号・`$…$` など）を外し、1 行は全角 36 文字まで
     （文の終わり「。」を一番に、次に読点のあたりで折る）、1 つの字幕は 2 行まで（スライドとステップのノートを続けて出すときは 4 行まで）。
     長いノートは、映している時間を文の長さで分けて、何枚かの字幕に続けて出します。続けて同じ字幕になる所は 1 つにまとめます。
     発表ウィンドウ・HTML・PowerPoint のノートは今までどおりです。
   - 出力中は進み具合（%）が出て、「やめる」で止められます（止めても、前に出力したファイルはそのまま残ります）。
19i. **全スライドからの検索・置換**: ツールバーの「検索・置換」（Ctrl+Shift+F・Ctrl+H）で、画面の右上に検索の欄を出します
   （開いたまま編集できます）。
   - 探す所: 文字（テキスト・表・グラフや図形のラベル・図形「コード」の中身）・数式（LaTeX）・発表者ノート（スライド・ステップ）・
     コード（ステップのコード・コードの行）。チェックで絞れます。要素の名前（変数名）・ファイル・色などの設定は探しません。
   - 「大文字・小文字を区別」「正規表現」（置き換えに `$1`・`$&`・`$<名前>` が使えます）、「すべてのスライド／今のスライド」。
   - 結果は、スライド・種類・要素の名前と欄（「scatter1 の表の見出し」など）と前後の文字で並び、押すとそのスライドの要素
     （ノート・コードはそのステップ）へ移ります。「この欄を置換」「すべて置換」。置換は「元に戻す」（Ctrl+Z）で 1 回で戻せます。
   - 書式付きのテキスト（一部の太字・色など）は、置き換えた文字に、置き換えの始まりの所の書式を付けます。
19j. **使っていないファイルの整理**: ツールバーの「ファイルの整理」で、`images`・`clips` フォルダのファイルを、次のように分けて出します。
   - **使っていないファイル**（初めから選んであります）
   - **バックアップや「元に戻す」の履歴だけが使っているファイル**（初めは選んでいません。移すと、そのバックアップに戻したときや
     元に戻したときに、ファイルが見つからなくなります）
   - ステップのコードなどにファイルの名前が書いてあるものは、使っているものとして扱います。アプリが作る仮のファイル（`.posters` など）は数えません。
   選んだファイルは、プロジェクトの `unused` フォルダへ移します（`images`・`clips` の区別は残します）。`unused` の中のファイルは
   「元の場所に戻す」「完全に削除」ができます。今のスライドで使っているのに `unused` にあるもの（移したあとで元に戻したなど）には印が出ます。
19k. **スライドが多いときの速さ**: 160 枚のプロジェクトで測り、次のようにしました。
   - スライド一覧のサムネイルは、スライドの中身が変わったものだけ描き直します（元に戻す・置換・設定の変更のたびに全部を描き直していたのを、
     160 枚で約 1 秒 → 0.01 秒に）。
   - 測った速さ（160 枚）: 開く 0.3 秒、スライドの切り替え 約 0.2 秒、元に戻す 0.07 秒、保存 0.03 秒、検索 0.2 秒・すべて置換 0.1 秒、
     書き出し（.py の生成）0.01 秒。描画（低画質）は 1 回目 26 秒、変えていないスライドは Manim のキャッシュが効き 2 回目から 16〜18 秒。
     描画の時間を減らしたいときは、「描画: 選んで描画…」で、直したスライドだけを描画できます。
19l. **プレゼン用リモコン（クリッカー）**: 発表ウィンドウで、PageDown で次へ、PageUp で前へ、「.」で黒画面（B と同じ。ページ番号を
   打っている間は、「3.2」の区切りとして使います）。黒画面・白画面の間は、情報ウィンドウに「黒画面中: B で戻る」と出ます。
   多くのリモコンが送るキーです（→・← を送るリモコンは、これまでどおり使えます）。
19m. **章（セクション）**: スライドのパネル（要素を選んでいないとき）の「章・付録・時間」で「このスライドから新しい章」にし、名前を付けます。
   - スライド一覧では、章の始まりのスライドの上に「■ 章の名前」が出ます。
   - 発表者用の情報ウィンドウの一覧では、章の始まりに【章の名前】が付き、上の「章」で絞り込み、「章の初めへ」で飛べます。
   - **スライドに出す**: 「プロジェクト設定」の「章の表示」で、章の名前・進み具合のバー（本編の中の進み具合。章ごとに区切る）・両方を選べます
     （初めは出さない）。名前の位置・バーの位置（上の端・下の端）・大きさ・色を決められ、スライドごとに「章の表示を隠す」こともできます。
     キャンバスにも同じ形で出ます。付録には出しません。
19n. **付録のスライド**: 「章・付録・時間」で「付録のスライド」にすると、どこに置いても本編の後ろにまとめて描画し、ページ番号は「A1」「A2」…になります。
   - 発表では、本編の最後で「次へ」を押しても付録には入りません（「本編の最後です」と出ます）。一覧・番号（「A1」Enter）・リンクで開きます。
   - スライド一覧では、紫の点線の枠と「付録 A1」の印が出ます。
   - HTML・PDF・PowerPoint には最後に入り、動画（mp4）には入りません。HTML でも、本編の最後で「次へ」を押すと本編の最後に留まります
     （付録は、リンクか、Esc の一覧で開きます）。
19o. **押すと飛ぶ（リンク）**: 要素のパネルの「押すと飛ぶ（リンク）」で、飛ぶ先のスライド、または「← 飛ぶ前の所へ戻る」を選びます。
   - 発表ウィンドウで、その要素を押すと（マウスを乗せると指の形）、そのスライドの初めへ飛びます。「戻る」で、リンクで飛ぶ前の所へ戻ります。
     リンクの上のクリックでは、次へは進みません。
   - 出力した HTML（「戻る」も働く）と PDF でも押せます。PDF の「戻る」は、そのスライドへ飛んでくるリンクが 1 か所だけならそのページへの
     リンクにし（どのソフトでも働く）、いくつもあるときは「前に見たページへ戻る」の命令にします（Acrobat などで働きます。
     PDF の標準の命令ではないため、ブラウザの PDF 表示などでは働かないことがあります）。
   - 押せる範囲は、スライドの初めの、その要素の位置と大きさです（描画のときに記録します）。
19p. **ページごとの目安の時間**: 「章・付録・時間」の「発表の目安」に、そのページにかける時間（「1:30」「90」など）を入れます。
   発表者用の情報ウィンドウに「このページ 0:42 ／ 目安 1:30」と出し、目安の 8 割で橙、過ぎると赤にします。
   全体のタイマーの「目安」が空なら、ページの目安の合計を入れます。
19q. **リハーサル（発表の練習）**: 情報ウィンドウの「● リハーサルを始める」で、区切りごとに、そこに居た時間を記録します。
   「■ リハーサルを終えて保存」か、発表ウィンドウを閉じると、プロジェクトの `rehearsals` フォルダに保存します。
   ツールバーの「リハーサル」で、記録を 2 つ選んで比べる表（ページ・題名・章・目安・時間・差、合計）を出し、次のことができます。
   - 「この記録の時間を『発表の目安』にする」（1・5・10・30 秒に丸める）
   - 「この記録で『動画での待ち』を決める」（区切りに居た時間から、動きの時間を引いたもの＝クリックを待った時間を、ステップ・スライドの
     「動画での待ち」に入れる。1 本の動画を、練習したときの間（ま）で書き出せます）
   どちらも「元に戻す」で戻せます。
19r. **スライドの点検**: ツールバーの「点検」で、画面の右上に、気になる所の一覧を出します（押すとそのスライド・要素を選びます）。
   - 調べること: 数式の誤り（MathJax で読めないもの）・画面からのはみ出し（カメラを動かしたスライドは、その画面に対して）・
     小さすぎる文字（20 未満）・背景との色の差が小さい文字（コントラスト比 3 未満）・リンクの飛ぶ先が無い・文字や画像どうしの重なり・
     画像や動画のファイルが無い・書き出せない設定・描画が古い（描画したあとに変えた）・録画に使うマイクやカメラ・発表用の画面の数。
   - 「無視する」で、その項目を次から出さないようにできます（プロジェクトに記録。「無視したもの」から戻せます）。
     数式の誤り・ファイルが無い・リンクの誤り・書き出せない設定は、無視できません。
   - **発表の前に自動で点検**（初めはオン）: 「描画・発表」で発表するときと「発表のみ」のとき、先に点検し、気になる所があれば
     「このまま続ける」「発表をやめて、点検の一覧を見る」を選ぶ画面を出します。一覧の下の欄か、その画面の「次から、発表の前に点検しない」で切れます。
19s. **配布資料（PDF）**: 「ファイルに出力…」の「配布資料（PDF）」で、描画した画面を用紙に並べた PDF を作ります。
   文字（題名・ノート・ページ番号）は PDF の文字として入るので、選んでコピーしたり、探したりできます。
   - 並べ方: 1・2・3 枚＋ノート（右側か下にそのページの発表者ノート）、2・3 枚＋メモ欄（右側に罫線）、4（2×2）・6（2×3）・9（3×3）枚（ノート無し）。
   - 用紙: A4・A3・B5（JIS）・Letter。向き: おまかせ（4 枚だけ横、ほかは縦）・縦・横。
     横向きでは、1 枚＋ノートは左に画面・右にノート、2・3 枚＋ノート／メモ欄は横に並べてそれぞれの下にノート／メモ欄、6 枚は 3×2 にします。スライドごと（最後の画面）か、ステップごと（クリックの区切りごと）か。
   - 各ページの上にプロジェクト名と日付、下に「n / 全体」を入れます。ノートが長いときは文字を小さくし、それでも入らなければ「…（以下略）」で切ります。
   - 文字のフォントは、プロジェクトの既定のフォントを探して使います（TrueType のもの。見つからなければ、PDF の標準の日本語フォント）。
     使ったフォントは、出力したあとの画面に出ます。
19t. **画像（PNG）・動く画像（GIF）**: 「ファイルに出力…」の「画像（PNG）」「動く画像（GIF）」で、`export/<クラス名>_png`・
   `export/<クラス名>_gif` フォルダに出力します。
   - PNG: スライドごと（最後の画面）か、ステップごと。名前は `p01.png`・`p03-2.png`（3 ページの 2 回目のクリック）・`pA1.png`（付録）。
     「発表で再生」の動画は、その時点のコマを重ねます。
   - GIF: スライドごとに、動きを初めから順につないだもの。幅（480〜1280）とコマの数（10〜30 / 秒）を選べます。最後の画面で 1.5 秒止まり、
     くり返し再生します（「発表で再生」の動画・音は入りません）。
   - 「PNG・GIF のページ」に「1-3, 5, A1」のように書くと、そのページだけを出力します（空ならすべて）。
19u. **持ち運び（zip に固める・zip から取り込む）**: ツールバーの「zip に固める」で、プロジェクトを 1 つの zip にします。
   - いつも入れるもの: `project.json`・`preamble.tex`・`images/`・`clips/`。選んで入れるもの: 描画の結果・バックアップ・録画・
     リハーサルの記録・出力したファイル。`unused/`（ファイルの整理で移したもの）と作り直せる一時ファイルは入れません。
   - 作った環境の情報（使っているフォント・LaTeX のパッケージ・アプリ／Manim／Manim Slides／Python の版・OS）も中に入れます。
   - ほかのパソコンでは、「開く」の「zip から取り込む…」（初めの画面の「zip から取り込む」）で、zip と取り出し先のフォルダを選びます。
     取り出し先の中に新しいフォルダを作って取り出し（同じ名前があれば「名前 (2)」）、そのまま開きます。
     開いたあと、足りないフォントや LaTeX のパッケージ、Manim の版の違いを一覧で出します。
   - Windows の「送る → 圧縮（zip 形式）フォルダー」で固めたプロジェクトのフォルダも取り込めます（日本語のファイル名も読めます）。
19v. **プロジェクトの削除・最近の一覧から外す**: 「開く」の画面と初めの画面の「最近のプロジェクト」の各行に、
   「一覧から外す」（フォルダはそのまま）と「削除…」があります。開いているプロジェクトは「プロジェクト設定」の
   「このプロジェクトを削除…」で削除できます（削除すると閉じて、初めの画面に戻ります）。
   - 削除は、フォルダを中のファイルごと **ごみ箱へ移します**（ごみ箱から元に戻せます）。確かめる画面で、名前・場所・ファイルの数と大きさを出し、
     「削除してよいことを確かめました」に印を付けてから移します。削除したプロジェクトは「最近のプロジェクト」から外します。
   - ごみ箱が無い場所（ネットワーク上のフォルダ・USB メモリなど）では、完全に消えてしまうため削除しません（エクスプローラーで削除してください）。
   - project.json の無いフォルダは削除しません。描画・出力・録画の組み立ての途中や、発表ウィンドウを開いている間も削除しません。
   - 一覧のフォルダがもう無いときに「削除…」を押すと、一覧から外します。
19w. **配置の補助（スマートガイド・グリッド・ガイド線）**: キャンバスの上の「表示 ▾」で切り替えます（どれも描画・出力には出ません）。
   - **スマートガイド**（初めはオン）: 要素を動かす・大きさを変えるときに、ほかの要素の端・中央、スライドの端・中央に合う所で
     ピンクの点線を出して吸い付きます。Alt を押している間は吸い付きません（回した要素・複数選んだときの大きさの変更は吸い付きません）。
   - **グリッド**: Manim の単位で 0.25・0.5・1 の間隔の方眼を出します（原点を通る線は少し濃く）。「グリッドに吸い付く」は表示と別にオン・オフできます。
   - 「線の端・曲線の点も、グリッド・ガイド線に吸い付く」（初めはオン）: 直線・矢印の端、吹き出しの尾の先、ベジェ曲線の点（ペンで置く点・点の編集で動かす点）も、
     ほかの要素の点に吸い付かないときは、グリッド（「グリッドに吸い付く」がオンのとき）とガイド線に、縦・横それぞれで吸い付きます。
   - **ガイド線**: スライドの上・左の帯からドラッグで、横・縦の線を引きます。線はドラッグで動かし、スライドの外へ出すと消えます。
     ダブルクリックか「数値で足す…」で、Manim の座標（中央が 0）で置けます。「中央に十字」「すべて消す」もあります。ガイド線はプロジェクトに保存し、元に戻せます。
   - 表示の設定（スマートガイド・グリッド）は、このブラウザに覚えます。
19x. **動きのプリセット**: 画面の下の「動きのプリセット ▾」で、選んだ要素によく使う動きを当てます（新しいステップとして足します）。
   - 組み込み: 出す（要素に合った出し方: 文字・数式は書く、図形は線を描く、画像はフェードイン）・フェードで出す・左／右から滑り込む・下から浮き上がる・
     上から降りてくる・中心から大きくなる・小さくから浮かび上がる・1 文字ずつ打つ／大きく光る・囲む・揺らす・光を放つ／フェードで消す・下へ消える・
     縮んで消える／出して強調・出して囲む・出して、次のクリックで消す（2 クリック）。要素に使えない動きは、似た動きに替えます（画像の「書く」はフェードイン など）。
   - 複数の要素を選んで当てるときは、その場で「1 クリックずつ（上から）」「1 クリックずつ（左から）」「同じクリックで少しずつずらす（秒）」「同じクリックで同時に」を選びます。
   - **自分のプリセット**: 下の欄で開いている（GUI の）ステップの、その要素の動き（時間・緩急・向き・速さの変化なども）に名前を付けて保存します。
     「続くステップも」で、同じ要素の続くステップもまとめて保存できます（例: 出して、次のクリックで消す）。ほかの要素・カメラの動きとコードの行は保存しません。
     保存したプリセットは、どのプロジェクトでも使えます（ユーザーの設定フォルダの `presets.json`）。× で消せます。
19y. **スライドマスター**: 全スライドに共通で出す要素（ロゴ・帯・フッターの文字など）と、題名の型・背景色・ページ番号と章の表示をまとめたものです。
   - スライドの一覧の上の「マスター」で、マスターの編集に入ります（左にマスターの一覧が出ます。「＋ 新しいマスター」「写す」「削除」）。
     キャンバス・レイヤー・要素のパネルがマスターを相手にし、テキスト・数式・図形・画像を置けます（「発表で再生」の動画・音声と、動き・リンクは付けません）。
     「スライドに戻る」かスライドを選ぶと、編集を終えます。
   - 要素を選んでいないときのパネルで、名前・「新しいスライドの既定にする」・背景色・ページ番号（プロジェクトに従う・出す・出さない）・
     章の表示を出さない、を決めます。スライドのパネルで、スライドごとに決めたものが優先です。
   - **題名の型**: マスターに「題名」の図形を置くと、その位置・大きさ・色・寄せ方・下線に、そのマスターのスライドの題名をそろえます
     （マスターの題名そのものは見本で、スライドには描きません。スライドに題名が無いときは何も出ません）。文字はスライドごとに書きます。
     左・右寄せのときは、マスターの題名の左端（右端）に、スライドの題名の文字の端をそろえます（文字の長さが違っても端がそろいます。キャンバスと描画で同じ位置）。
     型にそろえる題名は、スライドでは動かせません（変えるときは、マスターの題名を変えます）。
   - 題名を左・右寄せに切り替えると、一度だけ画面の端から 1 単位の所へ寄せます。そのあとは、ドラッグや数値で横の位置を自由に決められます
     （画面の幅の下線の題名だけは、下線が画面の中央にあるので、横には動きません）。
   - **自動で入る文字**: マスターのテキスト・数式・LaTeX の文章・箇条書きに `{プロジェクト名}`・`{日付}`・`{章}`・`{ページ}`・`{総ページ}` と書くと、
     スライドごとの値になります（日付は描画した日）。
   - スライドのパネルの「マスター」で、スライドごとに選びます（マスターなし も選べます）。新しいスライドは、既定のマスターになります。
   - スライドでは、マスターの要素をいちばん奥に薄く出します（選べません）。描画・発表・HTML・PDF・PowerPoint・動画・配布資料・画像のどれにも入ります。
     切り替え効果では、中身と一緒に動きます。
19z. **タイムライン（動きの欄）**: 画面の下の動きの欄の「一覧／タイムライン」で切り替えます。クリック（ステップ）ごとに、
   動き・待つ行を時間の帯（横軸が秒。出す＝緑・消す＝赤・強調＝橙・動かす＝青・待つ＝灰）で並べます。
   - 帯をドラッグすると始まり（前と同時・前の後に吸い付き、それ以外は「前の始まりから○秒後」）、右端をドラッグすると長さを変えます（0.05 秒刻み。Alt で吸い付かない）。
     帯を押すと、一覧に切り替えて、その行の編集を開きます。元に戻せます。
   - 自由なコードの行は区切りの印（その後の動きはコードの後から）、コードのステップは長さが分からないので「コード」の帯で出します（動かせません）。
19za. **発表全体の見通し**（ツールバーの「見通し」）: スライドごとに、動きの時間（描画される長さ）・目安の時間・リハーサルでかかった時間を横棒で並べ、
   章ごとの小計と全体の合計を出します。リハーサルが目安の 120% を超えるページ、動きだけで目安を超えるページは赤く出します。行を押すと、そのスライドへ移ります。
19zb. **バックアップの比較**: 「バックアップ」の一覧の「今と比べる」で、そのバックアップと今の内容を比べます。
   - 変えた・足した・消したスライドを、左右のサムネイル（バックアップ／今）と、変えた所の説明（要素の追加・削除、文字・位置・大きさ・色の変更、
     ステップ、ノート、スライドの設定）で出します。プロジェクト設定・マスター・スライドの並び・共通プリアンブルの違いも出します。
   - 「このスライドに戻す」で今のスライドをバックアップのスライドに置き換え、「このスライドを戻す」で消したスライドを元の位置に戻します（元に戻せます）。
     戻したスライドの変数名がほかのスライドと重なるときは、知らせます。
19zc. **出力設定の保存・まとめて出力**（「ファイルに出力…」の上）: 「この設定を保存…」で、今の形式とその設定に名前を付けて保存します
   （どのプロジェクトでも使えます。ユーザーの設定フォルダの `export_presets.json`）。「読み込む」で画面に戻し、「消す」で消します。
   「まとめて出力…」で、形式（今の画面の設定で）と保存した設定をいくつかチェックして、上から順に出力します（それぞれの結果を一覧に出します。「やめる」で、残りをやめます）。
   設定を保存していなくても、形式をチェックするだけで使えます。「すべて選ぶ」で全部をチェックでき、チェックは「ファイルに出力」を開くたびに外れます。
19zd. **表記ゆれ**（「点検」の「表記ゆれ」）: 英数字・かっこ・記号の全角と半角、句読点（、。と，．）、カタカナの伸ばし棒（「サーバー」と「サーバ」）、
   送り仮名・漢字とかな（「行う／行なう」「出来る／できる」「全て／すべて」など、よくある組）が混ざっている所を、どちらが何個かで出します。
   - 「こちらにそろえる」で、プロジェクトの中を一度にそろえます（1 回の「元に戻す」で戻せます）。「場所を見る」で「検索・置換」を開きます。「無視する」もできます。
   - 見るのは文字の部分（テキスト・LaTeX の文章・箇条書き・ラベル・ノート・マスター）だけで、`$…$` の数式・LaTeX の命令・コードは変えません。
     LaTeX の文章の % は特別な意味があるので、そろえません。
19ze. **数式の入力補助（Σ 記号）**: 数式の欄（と LaTeX の文章の欄）を選ぶと、欄の右上に「Σ 記号」が出ます。押すと記号の表が開きます。
   - 分類は「構造（分数・根号・添字・行列など）」「ギリシャ文字」「演算・関係」「矢印」「集合・論理」「関数」「最近」です。表の記号は、実際の数式の見た目で並びます。
   - 押すと、カーソルの位置に入ります。`\frac{▮}{▮}` の ▮ は入れる場所の目印で、文字を選んでから押すと、選んだ文字が最初の ▮ に入ります。

19zi. **定理・証明のブロック、番号、ラベルと参照**:
   - 「＋図形 ▾」の「定理・作図・計算」タブで、定理・定義・補題・命題・系・例・注意・証明のブロックを置きます。見出し（「定理 3.1（名前）」）・色の枠・本文（LaTeX の文章、数式は `$…$`）。
     本文は **1 行が 1 段落**で、「仮定:」「前提:」「条件:」で始めた行は青緑、「結論:」で始めた行は赤で強調します。
     証明は「何の証明か」でラベルを選ぶと「定理 3.1 の証明」になり、最後に ∎（証明の終わりの印）が付きます。
     左右のハンドルで、文字の大きさを変えずに幅を変えられます。

     種類ごとの名前（「Theorem」など）と色も変えられます。スライドの順と、スライドの中の上からの位置で数えます。

   - **ラベル**: どの要素にも、パネルの「番号・ラベル」でラベル（例: `thm:ivt`）を付けられます。数式には「式の番号 (1.1) を付ける」、画像・図形には「図の番号（キャプション）を付ける」があり、
     式の右に「(3.1)」、図の下に「図 3.1　説明」のテキストを置いて、一緒のグループにします（ふつうのテキストなので、位置・大きさ・説明の文を変えられます。`{番号}` の所が番号になります）。
   - **参照**: テキスト・数式・LaTeX の文章・定理の本文に `{ref:ラベル}` と書くと「定理 3.1」「(3.1)」「図 3.1」に、`{num:ラベル}` と書くと「3.1」になります（番号の無い要素は「p.5」のようにページ）。
     数式の欄の「Σ 記号」の「参照」タブ、テキストの「参照を入れる…」から選んで入れられます。描いた参照の文字は、発表ウィンドウ・HTML・PDF で押すと、ラベルの要素のスライドへ飛びます。
     見つからないラベル・同じラベルは「点検」で知らせます（参照は「??」と出ます）。

19zk. **計算した点列（数値計算・シミュレーション）**: 座標軸・座標平面を選んでから、「定理・作図・計算」タブの項目か、座標軸のパネルの「＋計算した点列」で置きます。
   描画（とプレビュー）のときに 1 回だけ計算します。乱数は「乱数の種」で決まるので、毎回同じ図になります。パネルに計算の結果（近似値・推定値）が出ます。
   - **Python のコード**: 変数 `pts` に (x, y) の並びを入れます（np・math・random・rng が使えます。(x, y, 1) は 2 つ目の色）。
   - **微分方程式の数値解**: y′ = f(x, y)（LaTeX か Python）を、オイラー法・ホイン法・ルンゲクッタ法（4 次）・精密（細かい刻み）で解きます。刻みや解き方を変えた点列を重ねると、誤りを比べられます。
   - **数値積分**: a〜b を n 等分した長方形（左端・右端・中点）か台形を並べます（近似値と、細かく分けた値を出します）。

   - **くり返しの試行**: さいころの目の平均・コインの表の割合の、回数ごとの変化（大数の法則）。
   - 見た目は折れ線・点・棒。点・棒・長方形は 1 つずつの部品なので、出す動きを「部品を少しずつずらして出す」にすると、1 つずつ増えていきます。

20a. **発表の仕方（くり返す・自動で次へ・発表者ノート）**: 画面の下でステップを開くと、見出しの下に次の欄があります。
   - **くり返す（次のクリックまで）**: そのステップの動きを、次のクリックまでくり返し再生します（manim-slides の `next_slide(loop=True)`）。
   - **終わったら自動で次へ**: そのステップの動きが終わったら、クリックを待たずに次のステップ（最後のステップなら次のスライド）へ進みます
     （`next_slide(auto_next=True)`）。「くり返す」とは同時に付けられません（片方を付けると、もう片方を外します）。
   - **発表者ノート**: そのステップを見せている間に出すメモです（Markdown が使えます。`next_slide(notes=…)`）。
     スライドのノート（下記）は、そのスライドのどの区切り（初めの表示・1-1・1-2 …）でも出し続け、ステップのノートは、その下に
     「【クリック 2】」のような見出しを付けて足します（HTML・PowerPoint に出力したノートも同じです）。
   - **発表ウィンドウでのノートの場所**: 発表者用の情報ウィンドウの、全ページの一覧の下に「発表者ノート（ページ 1）」の欄を出し、
     今のページのノートを大きめの文字で出します（manim-slides がもともと「次のスライド」の下に出す狭い欄は隠します）。
   - ステップの一覧には、⟳（くり返す）・⏭（自動で次へ）・✎（ノートあり）の印が付きます。「▷ このステップを試す」の小窓でも、
     くり返し・自動で次へが発表と同じように動き、ノートが下に出ます。
   - スライドのパネル（要素を選んでいないとき）の「発表（切り替え・自動・ノート）」では、スライドごとに次のものを決めます。
     - **切り替え効果**: 前のスライドからこのスライドへ進むときの動き。「なし」「重ねて切り替え（フェード）」「押し出す（ワイプ。向きを選ぶ）」
       「ズーム（近づく・遠ざかる）」と、その時間（秒）。ワイプとズームは manim-slides の `self.wipe`・`self.zoom` と同じ動きです。
       前のスライドの最後の画面を写した画像を動かすので、カメラを動かしたスライドや、焼き込んだ動画のあるスライドからでも、見た目がずれません。
       最初のスライドには付きません。1 枚だけの試し描画（▷ このスライドを試す）では、前のスライドが無いので見えません。
     - **初めの表示のあと、自動でステップ 1 へ**: スライドに入ったら（切り替え効果のあと）、クリックを待たずにステップ 1 を始めます。
     - **発表者ノート**: スライドの初めの表示（ステップ 1 の前）のノート。
   - スライドの一覧には、⇄（切り替え効果）・⏭（初めから自動）・✎（ノートあり）の印が付きます。
20b. **ファイルに出力（HTML・PDF・PowerPoint）**: ツールバーの「ファイルに出力…」で、直前に描画した結果を発表用のファイルにします
   （`manim-slides convert`）。出力先はプロジェクトの `export` フォルダで、「フォルダを開く」でその場所を開けます。
   描画したあとに内容を変えた場合や、まだ描画していない場合は、画面に注意が出ます（先に「▶ 描画・発表」で描画してください）。
   - **HTML**: ブラウザで発表します（reveal.js）。動き・くり返し・自動で次へ・発表者ノート（S キーで発表者用の画面）が使えます。
     `<クラス名>.html` と `<クラス名>_assets` フォルダ（動画と reveal.js）を一緒に持ち運びます。「1 つのファイルにまとめる」にすると、
     動画も HTML の中に入れます（ファイルが大きくなります）。背景色はスライドの背景色、題名はプロジェクト名になります。
     - reveal.js（ブラウザで発表するための部品）は、**初めての HTML の出力のときだけ**、確認の画面を出してから
       インターネット（cdn.jsdelivr.net）からダウンロードします。ダウンロードしたものは manim-slides がこのパソコンに保存し
       （ユーザーのキャッシュのフォルダの `manim-slides/revealjs6.0.1`）、次からはインターネットにつながずに出力できます。
       断った場合は出力しません（PDF・PowerPoint はダウンロードせずに出力できます）。
     - HTML では、最初と最後の区切りの「くり返す」はうまく動きません（manim-slides の制限。画面に注意が出ます）。
   - **PDF**: 動き・ノートは入りません。ページの分け方を選べます。
     - **ステップごと**: クリックの区切りごとの最後の画面を 1 ページずつ並べます（途中の様子も残ります）。
     - **スライドごと**: 各スライドの、最後のステップまで進めた画面だけを 1 ページにします（PowerPoint の PDF と同じ形。
       スライドの数とページの数、ページ番号がそろいます）。
   - **PowerPoint**: 区切りごとの動画を 1 枚ずつ並べます（クリックで再生）。発表者ノートも入ります。
     くり返し・自動で次へは、PowerPoint では働かないことがあります。
   - **「発表で再生」の動画・音声**も、出力したファイルに入れます（manim-slides convert は Manim の映像しか扱わないので、出力のあとに足します）。
     - HTML: 動画・音声のファイルを `<クラス名>_assets/media` に写し（1 つのファイルにまとめるときは HTML の中に入れます）、
       発表ウィンドウと同じ動き（区切りの始まりの状態、ステップの操作の時刻、くり返し、終わったときの扱い、フェード）をします。
       再生バー付きの動画は、クリックでも操作できます。発表者用の画面（S キー）の中の小さな画面では音を出しません。
       ブラウザによっては、最初のクリック（キー操作）より前は、音の出る自動の再生が止められることがあります。
     - PDF: 各ページ（区切りの最後の画面）に、その時点で見えている動画のコマ（再生前なら表紙の時刻のコマ）を入れます。音声は入りません。
     - PowerPoint: 区切りの間に見える動画・鳴る音声を、そのスライドに置きます（動画はその位置、音声は左上の小さな印。クリックで再生）。
       切り出し（始め・終わり）は入れますが、ステップの時刻どおりの自動の再生や音量の操作は入りません。

     と聞き、合わせます（編集した所より後ろの行をずらし、消した行だけを指していた指定は外します）。ステップ・コードの行の中の
     `code1.code_lines[k]` は書き換えず、行がずれた可能性をお知らせします。点検にも「行の指定がコードの行数を超えている」を足しました。
   - **表のセルに入れた要素は、表と一緒に出る・消える**ようにしました（セルの要素のパネルにその旨を表示）。セルの要素に自分の「＋出す」を足したときだけ、
     表とは別にその動きで出ます。**テキストの表の `$…$`** は、まわりの文字の高さに合わせて大きくします。
   - **貼り付け**: 「出す」動きのために初めは隠していた要素は、貼り付け先ではステップが無いので、初めから表示にします（お知らせ付き）。
     複数選択のパネルで、グループを含めて選んだときも、「スライド開始時に表示」と中心の x・y が効くようにしました。
   - **点検のコントラスト**: 文字の後ろにある塗った図形（マスターの帯も）・背景ボックスの色と比べます（紺の帯の上の白い文字を注意しない）。
     画像の上の文字は調べません。
   - **LaTeX の特別な文字**: 題名・LaTeX の文章・数式などの `# % & _ ^`（数式では `# %`）を点検で知らせ、「直す」で `\#` のようにします。
   - **環境チェックに「音声の出力先」**: 音声の出力先が無いと、発表ウィンドウ（Qt の動画の再生）が起動の途中で止まることがあります。
     発表ウィンドウが開けなかったときも、ログから音声の問題らしいときは、そのヒントを出します。
     開けたときも、音声の出力先が無ければ「音が出ません」の注意を出します（Windows で出力デバイスを無効にしたときなど）。
   - **見つからない LaTeX のパッケージ**: 環境チェックと描画のエラーで、ログの「File `xxx.sty' not found」から、ファイル名と
     `tlmgr install …` のコマンドを出します（ctexhook.sty → ctex のように、名前の違うものも一部対応）。
   - **TikZ・chemfig の線**: 共通プリアンブルで TikZ（chemfig・circuitikz など）を使うと線が消えていたのを直しました
     （PGF の出力を dvisvgm 用にし、線の太さを Manim の太さに直します）。
   - **描画の品質**を、ページを読み直しても覚えます。別のプロジェクトを開くと、前の描画の表示を消します。
   - **選んだスライドにもそろえる**: 左の一覧で複数のスライドを選んで要素を選ぶと、パネルに「選んだスライドにもそろえる」が出ます。
     同じ種類で同じ名前（末尾の数字を除く。`code4`・`code5`）の要素に、位置・大きさ・色・フォントを写します（元に戻せます）。
   - **線の膨らみのハンドル**: 線の真ん中のオレンジの丸をドラッグして曲げます（5° 刻み、Alt で 1° 刻み。角度を上に表示）。
   - **複数を選んで「＋出す」**: 行は選んだ順（Ctrl＋クリックで足した順）。「足す所」で「ステップ k に足す」も選べます。
   - **軌跡のたどる要素**を、パネルであとから変えられます。
   - **ステップの削除**は確かめずに消し、「元に戻す」ボタン付きでお知らせします。
   - **LaTeX の文字の書体**: プロジェクト設定で「明朝・ゴシック」を選べます（題名・LaTeX の文章・定理・表・ラベルなど。数式の文字は変わりません）。
   - **コードの既定の配色**を one-dark にしました（vim は暗い背景で `#include` などが読みにくいため）。
   - **新規作成で保存先のフォルダが無い**ときは、作るかを聞いて作ります。
   - **入力欄の中の Esc**: 1 回目で欄から外れ、2 回目で選択を解除します。
   - **部品（要素のテンプレート）**: よく使う要素の組（ベンゼン環・記号・図のひな形など）を 1 回作って保存し、2 回目からは 1 つの要素として置きます。
     - 作り方: 要素を複数選ぶ（グループを選ぶ）→ パネルの「部品として保存…」（「＋部品 ▾」の「選んだ要素を部品にする…」でも）。
       選んだ要素は、その場で部品 1 つに置き換わります。入れられるのはテキスト・数式と、ほかの要素に付かない図形です
       （画像・動画・座標軸に付くグラフなどは入れられません）。
     - 置き方: キャンバスの上の「＋部品 ▾」から選びます。部品は、このパソコンのどのプロジェクトでも使えます（保存先はユーザー設定の `parts/`）。
       置くと、プロジェクトに中身の写しを持つので、zip で持ち運んでもそのまま描けます。
     - 大きさ（倍率）・回転・位置を変えられます。動きの中では 1 つの要素です（一部分だけ動かすときは「一部分…」）。コードでは `part1[0]` などで中の要素を参照できます。
     - **直す**: 部品のパネルの「部品を直す…」でばらし、直したあと、グループのパネルの「部品「…」を上書き」を押すと、
       置いた所がすべて変わります（そのとき直した部品の大きさ・向きは保ちます）。ほかのプロジェクトは、次に開いたときに新しい版になります。
     - 別の PC で作った部品（zip で受け取ったプロジェクト）は、そのまま描けます。「＋部品 ▾」の「このプロジェクトの部品」から置け、「この PC に保存」でほかのプロジェクトでも使えます。
     - **ばらす**: その場所だけ、普通の要素（グループ）に戻します（部品とのつながりは切れます）。
     - 「＋部品 ▾」で、名前の変更・削除ができます（削除しても、置いた部品はプロジェクトの写しで描けます）。

19zn. **3D・統計のグラフ・定理の確認からの改善**:
   - **別のタブで別のプロジェクトを開いたとき**: 前のタブに「このタブでは保存できません」と出て、保存・自動保存を止めます（あとで開いたプロジェクトを上書きしないため。サーバーも照らし合わせて断ります）。
     「このタブで作業を続ける」で、そのタブのプロジェクトを開き直し、そのタブの内容で保存します。
   - **3D**: 円錐の底面・円柱の上下の面・直方体の面を細かい面にして、ほかの立体との手前・奥を正しく描きます。キャンバスの重なりは奥行きの順（既定）。
     カメラのマウス操作、描画の時間の知らせ、高（1080p・30fps）、2 回目からの描き直しの省略は「18. 3D」を見てください。
     3D を使わないプロジェクトには、3D の要素を貼り付けません。点検は、未保存の変更を保存してから調べます。
   - **統計のグラフ**: 区切りの判定、全角のカンマ、凡例の位置、500 行の知らせ、目盛りの 0、四分位数の求め方（教科書が既定）は「13j」を見てください。
     「＋出す」では、誤差棒・回帰直線を、点・棒が出たあとに出します。
   - **定理と参照**: 参照を押すと、その要素が画面に出るクリックへ飛びます（段落ごとに出す定理も、飛んだ直後に見えます）。
     プロジェクト設定の「定理・番号」の「証明の見出し」で、証明の見出しの形を変えられます（例: 「{証明} of {対象}」）。
   - ツールバーの「描画: 印の通り（n / n 枚）」は、スライドを足したときなどにすぐ数え直します。テキストの「自動で折り返す」の初めの幅は、スライドの幅までにします。
     描画の最中のプレビューは、待ち時間を延ばし、断られたら 1 回だけやり直します。
   - **3D のカメラの中心**: Manim の 3D のカメラは、中心を動かすと 2 回ずれ、しかも最初のコマの中心を使い回すため、
     スライドを移っても前のスライドの中心が残っていました。直したカメラを使うので、スライドごとの中心・ステップでの中心の移動が正しく描かれます
     （以前に中心を動かしたスライドは、ずれが半分になります。キャンバスと描画は同じ位置になります）。

## プロジェクトのフォルダ

```
my-deck/
├── project.json      # 編集内容（設定・スライド・要素・コード）
├── preamble.tex      # 共通プリアンブル（UTF-8）
├── images/           # 取り込んだ画像（名前-内容のハッシュ.png など）
├── clips/            # 取り込んだ動画・音声（名前-内容のハッシュ.mp4 など。.posters/ はポスターの画像）
├── Deck.py           # 書き出した Manim Slides のコード（クラス名はプロジェクト名から生成）
├── Deck.map.json     # 生成した .py の行番号と、元の位置の対応表（エラー位置の表示に使う）
├── media/            # Manim の描画結果
├── slides/           # manim-slides の出力（発表に使う）
├── export/           # 「ファイルに出力」で作った HTML・PDF・PowerPoint・動画・配布資料・画像
├── backups/          # バックアップ
├── recordings/       # 発表の録画
├── rehearsals/       # リハーサルの記録
└── unused/           # 「ファイルの整理」で移した、使っていないファイル
```

`Deck.py`・`Deck.map.json`・`media/`・`slides/` は、`project.json` と `preamble.tex` から作り直せます。
書き出した `.py` は、ターミナルからも使えます。

```
manim-slides render Deck.py Deck
manim-slides present Deck
```

## 注意

- テキストは、ふつうは改行（Enter）を入れた位置でだけ折り返します。決めた幅で折り返すときは、テキストの「段落」の
  「自動で折り返す」をオンにします（19zg。横書きのみ。初めはオフ）。
- **数式のキャンバス表示は仮表示**です。数式は MathJax、文字はブラウザで描いた近似なので、字幅や行間が実際と少し違います。
  正確な見た目は描画（発表ウィンドウ）で確認してください。
- MathJax に無いコマンド（`\usepackage` に依存するもの、TikZ など）は、仮表示では赤字になります。
  描画では XeLaTeX がそのまま処理します。よく使う `\textcircled` は、仮表示用の代用を用意しています。
- アニメーションのコード欄は、書いた Python をそのまま書き出します。JSON を開いただけではコードは動きませんが、
  描画や書き出した `.py` の実行でコードが動きます。出所の分からないプロジェクトは、内容を確認してから描画してください。
- サーバーは 127.0.0.1 だけで待ち受け、起動ごとのトークンと Host ヘッダーを確認します（ほかの Web サイトから
  操作されないようにするため）。

## 困ったとき

| 症状 | 対処 |
| --- | --- |
| 描画・発表ボタンが押せない | 「環境チェック」を開き、✕ の項目のヒントに従います。TeX Live を入れた直後は、ターミナルを開き直します。 |
| 画像を含むスライドで `ValueError: Invalid mode for data type` | Pillow 13（2026-10-15 公開）では manim 0.20.1 が画像を描けません。`conda install -c conda-forge "pillow<13"` で Pillow 12 に戻し、アプリを起動し直してください。 |
| `write_to_movie` のエラー | manim が 0.22 系です。`conda install -c conda-forge manim=0.20.1` で戻してください。 |
| 発表ウィンドウが開かない | 下のパネルに表示されるログを確認します。`QtMultimedia` の DLL が見つからない場合は、`conda install -c conda-forge qt6-multimedia` を実行します。 |
| フォントが反映されない | 環境チェックでそのフォントが ✓ か確認します。導入後はアプリを再起動します。 |
| 更新したのに新しい機能のボタンが反応しない | アプリ（start.bat）を一度終了して起動し直します。それでも直らなければ、ブラウザで Ctrl+F5 を押します。現在の版は、画面のファイルが変わると自動で読み直します。 |
| 描画に時間がかかる | ステータスバーと下のパネルに、全体の割合・いま描いている区切り（スライドとステップ）・残り時間の目安が出ます。画像を動かすアニメーションは時間がかかるので、確認には低い品質を使います。 |
| 数式が赤字になる | 仮表示で扱えないコマンドです。描画では正しく出るか、描画で確認します。 |
